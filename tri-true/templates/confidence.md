# 三层置信度明细 + 知识类型分类

> 本报告列出每个段落的三层置信度（VC/SC/CC）、综合置信度及知识类型分类，含校准模型与 ECE。
> 知识类型与置信度是同级并行属性——置信度回答"多确信"，知识类型回答"确信的依据是什么"。

## 置信度综合公式

```
composite_confidence = 0.4 × VC + 0.3 × SC + 0.3 × CC

其中：
- VC (Verbalized Confidence) = LLM 自评把握度 / 100
- SC (Self-Consistency) = N 次采样 top-k 一致度 = max_count / N
- CC (Calibrated Confidence) = VC × k，k = 1 - ECE
```
