# 动效术语反查词典（motion-vocabulary.md）

> 把对动效的**模糊描述**变成**确切术语**（"弹出层打开时那个弹一下的东西" → Pop in；"iOS 那种橡皮筋滚动" → Rubber-banding）。
> 用途：用户问"这个叫什么"、或描述了效果却不知道名字、需要准确词汇去提示 AI 或设计师时。**用于命名效果，不用于设计或构建效果。**
> 来源与归属：蒸馏自 emilkowalski/skills（MIT License, Copyright (c) 2026 Emil Kowalski），去产品化改写并中文化。
> grep 检索：`grep -n "^### " references/motion-vocabulary.md`

## 用法

用户松散地描述一个效果，你按此格式返回匹配术语：

```
**Stagger 交错** —— 依次动画若干元素，每项之间留一个小延迟，形成瀑布般的层叠。
```

若多个术语都沾边，先给最佳匹配，再给 1–2 个替代项并各附一行说明差异。

### 六条指令

1. **按意图读，不按关键词读。** 用户描述的是他们**看到或感觉到**的东西（"弹弹的""滑出去""自己画出来"），不是技术名称。把感受映射到下表。
2. **逐字引用本词典。** 其描述是权威的——原样使用，NEVER 改写。
3. **消歧相近术语。** 两者竞争时（*Clip-path* vs *Mask*、*Pop in* vs *Bounce*、*Shared element transition* vs *Layout animation*），对照说明以便用户选择。
4. **没有精确匹配时，** 给出最接近的术语并坦白说明这是近似，或用本词典的词汇描述该效果（如"那是若干 *scale-in* 入场的 *stagger*"）。
5. **留在本词典之内。** 若某术语确实不在此，直说，NEVER 发明一个——但 MAY 用这些词解释该概念。
6. **保持紧凑。** 命名问题要的是名字，不是文章。先给术语，被追问再展开。

### 示例

**例 1 —— 基于感受**
用户："弹出层看起来是从你点开的那个按钮里长出来的，而不是从它自己的中间——这叫什么？"
输出：
```
**Origin-aware animation 原点感知动画** —— 元素从它的触发器动画长出，如弹出层从打开它的按钮长出，而非从 CSS 默认的自身中心。
```

**例 2 —— 消歧**
用户："一张图变成另一张图的那个。"
输出：
```
**Morph 形变** —— 一个形状平滑地变成另一个形状，例如 Dynamic Island。

相近替代：
- **Crossfade 交叉淡入** —— 若它们只是叠在原位互相淡入淡出。
- **Shared element transition 共享元素过渡** —— 若一个元素从一个位置行进并变换到另一个位置。
```

**例 3 —— 物理感受**
用户："iOS 那种滚动，拉过头会抵抗然后弹回来。"
输出：
```
**Rubber-banding 橡皮筋** —— 拖过边界时的阻力与回弹（iOS 的越界滚动手感）。
```

## 词典

### 入场与出场 — 元素如何出现与消失
- **Fade in / Fade out 淡入 / 淡出** —— 元素通过改变 opacity 出现或消失。
- **Slide in 滑入** —— 元素从屏幕外（左、右、上或下）滑入。
- **Scale in 缩放进入** —— 元素出现时由小长到实际大小，常与淡入配对。
- **Pop in 弹入** —— 元素带着轻微过冲出现，像弹跳着落位。
- **Reveal 揭示** —— 内容逐渐被揭开，常通过动画 clip-path 或 mask 实现。
- **Enter / Exit 入场 / 出场** —— 元素被加入或移出屏幕时播放的动画。

### 时序与编排 — 协调多个元素或多个时刻
- **Keyframes 关键帧** —— 动画中的已定义点（0%、50%、100%），浏览器负责填补其间的空档。
- **Interpolation / Tween 插值 / 补间** —— 生成起止值之间的全部中间帧，使运动连续。
- **Stagger 交错** —— 依次动画若干元素，每项之间留一个小延迟，形成瀑布般的层叠。
- **Orchestration 编排** —— 刻意安排多个动画的时序，让它们感觉像一次协调的运动。
- **Delay 延迟** —— 动画开始前的等待时间。
- **Duration 时长** —— 动画持续多久。
- **Fill mode 填充模式** —— 动画开始前或结束后，元素是否保留首帧或末帧的样式（如 `forwards`）。
- **Stepped animation 阶跃动画** —— 被切分为离散步进的动画，如倒计时器。

### 位移与变换 — 改变元素的位置、尺寸或角度
- **Translate 平移** —— 沿 X 或 Y 轴移动元素。
- **Scale 缩放** —— 让元素变大或变小。
- **Rotate 旋转** —— 绕某一点转动元素。
- **Skew 斜切** —— 沿 X 或 Y 轴倾斜元素，把它剪切出矩形。
- **3D tilt / Flip 3D 倾斜 / 翻转** —— 在 3D 空间中旋转（rotateX / rotateY）以增加深度。
- **Perspective 透视** —— 3D 效果有多强——值越低深度越夸张，像观察者离得更近。
- **Transform origin 变换原点** —— 缩放或旋转所围绕的锚点。
- **Origin-aware animation 原点感知动画** —— 元素从它的触发器动画长出，如弹出层从打开它的按钮长出，而非从 CSS 默认的自身中心。

### 状态间过渡 — 连接一个状态、视图或元素到另一个
- **Crossfade 交叉淡入** —— 一个元素淡出的同时另一个在原位淡入。
- **Continuity transition 连续性过渡** —— 通过在视觉上连接前后状态来保持用户方向感的变更。例如让同一个矩形变大变小。
- **Morph 形变** —— 一个形状平滑地变成另一个形状，例如 Dynamic Island。
- **Shared element transition 共享元素过渡** —— 一个元素从一个位置行进并变换到另一个位置，如缩略图展开成卡片。
- **Layout animation 布局动画** —— 元素的尺寸或位置变化时，它动画到新位置而非硬跳。
- **Accordion / Collapse 手风琴 / 折叠** —— 一个区块平滑地展开与收起其高度以显示或隐藏内容。
- **Direction-aware transition 方向感知过渡** —— 前进时内容朝一侧滑动、返回时朝相反侧，使导航具有方向感。

### 滚动 — 与滚动或视图间导航绑定的动效
- **Scroll reveal 滚动揭示** —— 元素进入视口时淡入或滑入到位。
- **Scroll-driven animation 滚动驱动动画** —— 进度与滚动位置直接绑定的动画。
- **Parallax 视差** —— 滚动时背景与前景以不同速度移动，营造深度。
- **Page transition 页面过渡** —— 从一个页面或路由导航到另一个时播放的动画。
- **View transition 视图过渡** —— 浏览器在两个状态或页面之间形变，连接共享元素。

### 反馈与交互 — 响应用户动作
- **Hover effect 悬停效果** —— 光标移到元素上时的视觉变化。
- **Press / Tap feedback 按压 / 点击反馈** —— 元素被点击时轻微缩小，使其感觉有实体感。
- **Hold to confirm 长按确认** —— 用户按住按钮期间逐渐填满的进度效果。
- **Drag 拖拽** —— 抓住元素移动它，释放时常带有动量。
- **Drag to reorder 拖拽重排** —— 拖动列表中的项来重排，其余项让位。
- **Swipe to dismiss 滑动消除** —— 把元素拖出屏幕以关闭它，如抽屉或 toast。
- **Rubber-banding 橡皮筋** —— 拖过边界时的阻力与回弹（iOS 的越界滚动手感）。
- **Shake / Wiggle 抖动** —— 快速的左右颤动，表示错误或被拒绝的输入。
- **Ripple 涟漪** —— 从点击点扩散开的圆，确认该次按压。

### 缓动 — 速度如何随时间变化
- **Easing 缓动** —— 动画加速与减速的速率。
- **Ease-out 缓出** —— 起步快，结束慢。大多数 UI 以及任何响应用户的动作的默认选择。
- **Ease-in 缓入** —— 起步慢，结束快。通常应避免；会让人觉得迟钝。
- **Ease-in-out 缓入缓出** —— 慢、快、慢。适合屏幕上已存在的元素从 A 移到 B。
- **Linear 线性** —— 匀速。UI 中应避免；留给 spinner 或跑马灯。
- **Cubic-bezier 三次贝塞尔** —— 为精确控制而自定义的缓动曲线。
- **Asymmetric easing 非对称缓动** —— 加速与减速速率不同的曲线。比对称的更"活"。

### 弹簧动画 — 以物理驱动的运动替代固定时长缓动
- **Spring 弹簧** —— 由物理（张力、质量、阻尼）驱动的运动，而非设定的时长。
- **Stiffness / Tension 刚度 / 张力** —— 弹簧把值拉向目标有多强。越高感觉越利落。
- **Damping 阻尼** —— 弹簧多快稳定下来。阻尼越低，回弹与振荡越多。
- **Mass 质量** —— 被动画元素感觉有多重。质量越大越慢、越迟钝。
- **Bounce 回弹** —— 过冲后稳定的弹簧，增加玩趣感。
- **Perceptual duration 感知时长** —— 弹簧**感觉**上多久结束，尽管底下还在微幅收敛。
- **Momentum 动量** —— 携带速度的运动，尤其在拖拽或中断之后。
- **Velocity 速度** —— 元素移动得多快、朝哪个方向。被中断时弹簧把它带进下一段动画，因此被甩出去的元素会保持其速度。
- **Interruptible animation 可中断动画** —— 可在飞行途中被平滑重定向的动画，而不必先播完。

### 循环与环境动效 — 自行运行的动画
- **Marquee 跑马灯** —— 循环连续滚动的文字或内容。
- **Loop 循环** —— 重复播放的动画，可设定次数或无限。
- **Alternate (yoyo) 往复（溜溜球）** —— 每次迭代先正放再倒放的循环，而非跳回起点。
- **Orbit 环绕** —— 元素沿连续路径绕另一个转圈。
- **Pulse 脉冲** —— 温和重复的缩放或透明度变化，以吸引注意。
- **Float 漂浮** —— 温和、连续的上下漂移，让静态元素感觉是活的、失重的。
- **Idle animation 待机动画** —— 元素只是停在那里等待交互时播放的细微动效。

### 打磨与特效 — 区分好与卓越的小细节
- **Blur 模糊** —— 用于柔化元素或遮掩微小瑕疵的滤镜。
- **Clip-path 裁剪路径** —— 把元素裁成某个形状，用于揭示、遮罩与前后对比滑块。
- **Mask 遮罩** —— 用形状或渐变隐藏或揭示元素的局部——类似 clip-path，但边缘柔软可淡出。
- **Before / after slider 前后对比滑块** —— 可拖动的分割线，在两张叠放的图像间擦除以做比较。
- **Line drawing 线条描绘** —— SVG 路径自己画出来，像一支看不见的笔在描它。
- **Text morph 文字形变** —— 文字变化时逐字符动画，把注意力引向新值。
- **Skeleton / Shimmer 骨架屏 / 微光** —— 内容加载期间显示的带流动光泽的占位符。
- **Number ticker 数字滚动** —— 数字滚动或累加到某个值。
- **Tabular numbers 等宽数字** —— 固定宽度的数字，使其在变化时不左右跳动。对滚动数字、计时器与计数器至关重要。
- **Typewriter 打字机** —— 文字逐字符出现，像正在被敲进去。

### 性能 — 让运动平滑而非卡顿
- **Frame rate (FPS) 帧率** —— 每秒绘制的帧数。60fps 是流畅运动的基线；新显示器上为 120fps。
- **Jank 卡顿** —— 浏览器因跟不上动画而掉帧造成的可见抖动。
- **Dropped frame 掉帧** —— 浏览器错过了绘制时限的一帧，造成运动中的微小顿挫。
- **Compositing 合成** —— 让 GPU 在自己的层上移动或淡入淡出元素，而不必重做 layout 或 paint。
- **will-change** —— 提示元素即将动画的 CSS 属性，让浏览器提前把它提升到独立层。
- **Layout thrashing 布局抖动** —— 动画 `width`、`height`、`top`、`left` 这类属性，迫使浏览器每帧重算布局，造成卡顿。

### 应知原则 — 指导何时动、怎么动
- **Purposeful animation 有目的的动效** —— 运动应当服务某个功能——定向、给反馈、展示关系——而不只是装饰。
- **Anticipation 预备动作** —— 移动前朝反方向的一个小预备，暗示即将发生什么。
- **Follow-through 跟随动作** —— 主体运动停止后，元素的一部分继续移动并轻微收住，增加重量感。
- **Squash & stretch 挤压与拉伸** —— 移动时让元素变形以传达重量、速度与柔韧性。
- **Perceived performance 感知性能** —— 正确的动画让界面**感觉**更快，即使实际并没有更快。
- **Frequency of use 使用频率** —— 用户看到某动画越频繁，它就越应该更短、更弱。
- **Spatial consistency 空间一致性** —— 让元素跨状态保持其身份与位置的动画方式，使用户永不丢失"东西去哪了"的线索。
- **Hardware acceleration 硬件加速** —— 动画 transform 与 opacity 能让 GPU 保持运动平滑。
- **Reduced motion 减弱动效** —— 尊重用户的 prefers-reduced-motion 设置，弱化或去掉运动。
