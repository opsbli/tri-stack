## 1. 模式一 · 灵感创作指令（无歌词、先想法）

> 适用场景：快速验证灵感、A/B 测试不同方向

### 模板结构

```markdown
【灵感词句】（20 字以内 · 主题+情绪+核心意象）
[填写示例：独弦琴在海风中弹奏千年孤独]

【曲风选择】（必填 1-2 个）
- 国风 / 中国风 / 古风 / 国风电子 / 国风摇滚 / 民谣 / 流行 / 抒情 / 电子

【心情/氛围】（必填 1 个）
- 欢快 / 舒缓 / 伤感 / 激昂 / 深沉 / 励志 / 宁静 / 浪漫

【音色选择】（必填 1 个）
- 男声 / 女声

【反 AI 罐头指令 · 必加】
（自动追加 prompts/anti-can.md 全文）
```

### 完整示例

```markdown
【灵感词句】
京族独弦琴的一根弦，弹尽千年海洋孤独

【曲风选择】
国风电子

【心情/氛围】
深沉

【音色选择】
男声（带沙哑叙事感）

【反 AI 罐头指令】
- 副歌必须包含"独弦"这个不可替换的具体意象
- 避免主歌+8 度直入副歌的最常见套路
- 编曲必须有独弦琴或箫的标志性独奏段落
- 副歌金句"独弦啊独弦"重复 ≥ 2 次
- 不要使用 1645 标准 POP 和弦进行
- 加入海浪声环境音作为情绪衬底
```

## 3. 海绵音乐专属调优技巧

### 技巧 ① · 提示词中文 > 英文
中文提示词识别率显著高于英文。

### 技巧 ② · 具体意象 > 抽象情绪
"独弦琴在海风中弹奏千年孤独" > "悲伤的古风音乐"。

### 技巧 ③ · 乐段指令必须含 BPM
"副歌 120 BPM 的 Future Bass" > "副歌节奏感强"。

### 技巧 ④ · 反 AI 罐头基底必加
由于海绵音乐训练数据"抖音化"，必须显式追加 `prompts/anti-can.md` 才能避免同质化。

### 技巧 ⑤ · 一次生成 3 首 → 选最优
海绵音乐一次输出 3 首，挑选后微调比"反复要求重做"更高效。

## 4. 海绵音乐 3 套差异化指令（按场景）

### 场景 ① · 国风/古风/非遗

```markdown
【曲风】国风 / 古风
【音色】男声（带沙哑叙事感）/ 女声（带戏曲唱腔）
【进阶提示词】前奏以独弦琴/二胡/箫独奏引入，副歌加入电子鼓点但保留五声音阶主旋律，编曲从简到繁层层递进，加入传统乐器演奏技法（古筝摇指+二胡滑音）

【反 AI 罐头 · 国风专项】（自动追加 prompts/anti-can.md §2）
```

### 场景 ② · 都市情感/治愈

```markdown
【曲风】流行 / 抒情
【音色】男声（克制中带着隐忍）/ 女声（温柔有故事感）
【进阶提示词】主歌用轻声叙述、副歌用真声爆发，尾音带气声；编曲以钢琴为主、副歌加弦乐铺底；加入城市环境音（地铁/便利店/雨声）作为情绪衬底

【反 AI 罐头 · 通用版】（自动追加）
```

### 场景 ③ · 热血/卡点/DJ

```markdown
【曲风】电子 / DJ 改编
【音色】男声（爆发力强）/ 女声（高亢穿透力）
【进阶提示词】120-138 BPM 鼓点驱动、副歌加合成器 hook，主歌与副歌节奏反差强烈，加入特定电子元素（Future Bass / 鼓点失真 / 切片）

【反 AI 罐头 · DJ 改编专项】（自动追加 prompts/anti-can.md §3）
```

## 5. 常见错误与避坑

| 错误 | 后果 | 解决方案 |
|---|---|---|
| ❌ 提示词用"悲伤的""欢快的"等抽象情绪 | 输出模板化 | 用"编辑 10 遍没发的消息"等具体意象 |
| ❌ 提示词不指定 BPM | 节奏不匹配平台 | 显式指定 BPM（教育 60/民谣 80-100/运动 120/卡点 138） |
| ❌ 不追加反 AI 罐头指令 | 输出"千篇一律的爆款感" | 自动追加 `prompts/anti-can.md` |
| ❌ 一次性要求"复杂编曲+人声+和声" | 输出质量下降 | 拆分为"主歌+预副歌+副歌"分段生成 |
| ❌ 不指定具体乐器/演奏技法 | 国风编曲模板化 | 指定"古筝摇指+二胡滑音"等具体技法 |
