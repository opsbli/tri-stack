## 3. 完整示例

```markdown
【场景描述】
上周三凌晨 3 点，我加班回家，路过 24 小时便利店，看到一个穿西装的男人坐在门口吃关东煮，眼睛红红的。他也没哭，就是看着那碗汤发呆。我想写一首关于"成年人的崩溃静悄悄"的歌。

【情绪关键词】
都市、深夜、孤独、克制

【参考元素】
24 小时便利店、关东煮、西装、凌晨、红眼睛

【风格倾向】
流行 / 民谣

【反 AI 罐头指令】
- 副歌必须包含"便利店""关东煮"等具体意象，不能用"我好孤独"等抽象词
- 避免主歌+8 度直入副歌的最常见 POP 套路
- 编曲必须有凌晨街道的环境音采样
- 副歌金句"4-7 字"+"重复 ≥ 2 次"
- 不要使用 1645 标准 POP 和弦进行
- 歌词使用"具体到毛孔"的微情绪
```

## 4. Melo 多模态输入

### 输入 ① · 文字
最常用，"聊天式"自然语言描述。

### 输入 ② · 图片
- 上传某张照片（人像/风景/物品）
- Melo 自动识别场景+情绪+风格
- **适合**：朋友圈图、日落、咖啡、宠物

### 输入 ③ · 视频
- 15s 短视频
- Melo 识别画面+背景音
- **适合**：vlog 配乐

### 输入 ④ · 链接
- 粘贴某篇文章/小红书/微博链接
- Melo 抓取文字+图片，转化为音乐
- **适合**：日记、信件、随笔

### 输入 ⑤ · 音频
- 上传一段录音（自己的声音/环境音）
- Melo 提取特征+生成音乐
- **适合**：翻唱、ASMR 改编

## 7. 常见错误与避坑

| 错误 | 后果 | 解决方案 |
|---|---|---|
| ❌ 场景描述用"我想写一首伤感的歌" | 输出模板化 | "今天和 X X 一起 X X X，X X X 让我想哭" |
| ❌ 期望专业级国风还原 | 小程序无法满足 | 国风用 App 或改用 Udio |
| ❌ 一次输入大量抽象情绪词 | 输出混乱 | 控制在 1-2 个具体场景 |
| ❌ 不上传图片/视频 | 错过多模态优势 | 充分利用"生活即灵感" |
| ❌ 期望免费版商用 | 版权风险 | 确认订阅条款 |
