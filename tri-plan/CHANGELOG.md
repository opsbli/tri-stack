# Changelog

本文件记录 tri-plan skill 的版本变更历史。

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。


## [1.3.2] - 2026-09-24

### 变更

- **版本门节收敛为瘦指针 STUB**：`## 版本检查与更新机制` 由 35 行全量版收敛为 14 行（执行方式 + 真源指针），移除已失效的**远端 skillhub 内联细则**（端点解析 / 四态判定 / 升级流程 / SemVer 比较算法）。依据 `references/version-check-spec.md` §六（该节须 ≤30 行、禁内联细则）；本仓库已转自维护 fork（`scripts/check_update.py` 内置 `SELF_MAINTAINED = True`，完全跳过远端请求），原节描述的行为**永不执行**。
- **强制执行契约 §0 同步修正**：版本门措辞由「连接 skillhub 校验版本，非最新版 MUST 自动执行 `skillhub upgrade <slug>` 升级」改为「运行 `scripts/check_update.py` 做本地版本一致性校验，本仓库为自维护 fork、不做远端比对」，消除 prompt 层与脚本实际行为的直接矛盾。
- 非功能性变更（文档口径），无行为变更。

## [1.3.1] - 2026-09-24

### 变更

- **分支收窄为编程工作流专线（22 skill）**：清理对已移除 skill 的交叉引用——职责边界表 / 不由本 skill 处理表的对应行改为「本分支未包含（原 tri-xxx）」或删除；已删的委派关系与相邻边界说明同步失效。非功能性变更（文档）。

## [1.3.0] - 2026-09-20

### 新增

- **计划缺陷禁令（占位符零容忍）**（蒸馏自实现计划编写方法论）：「待定/TODO/类似任务 N/添加适当的错误处理/只描述做什么」等计划缺陷模式 MUST 绝不出现，含分类禁令清单。
- **计划自检三查**（门②审计前自检）：覆盖度（任务要点逐条有承接任务）、占位符扫描、跨任务一致性（类型/接口/文件名引用一致）。
- **任务粒度定界判据**：一个任务 = 能独立承载自己那轮验证循环、且值得一次独立审查把关的最小单元，以可独立验证的交付物结束。
- **task-checklist 全局约束节**（SKILL.md 产物结构 + templates/task-checklist.md 同步）：项目级硬要求逐字照抄、随清单下发，执行 skill 无需回读 plan.md；质量标准同步加「无占位符」「跨任务一致性」两行。

## [1.2.3] - 2026-09-18

### 新增

- **职责边界补「不触发场景（Not-Trigger）」**（对齐全家族 skill 写作规范）：明确本 skill 不接手编码实现/动手执行（tri-coding / tri-action）、工作流设计与全生命周期编排（tri-workflow / tri-sdlc）、内容文本产出（tri-content）与意图识别（tri-intent），强化「只出方案不执行」边界。

## [1.2.2] - 2026-09-12

### 新增

- **任务清单复选框不渲染**：`templates/task-checklist.md` 原写法 `- **完成状态**：- [ ]` 中 `- [ ]` 不在行首，GFM 下渲染为纯文本而非可勾选控件（已用 markdown-it + tasklists 插件实测）。改为 `- [ ] **完成状态**：未确认`，`SKILL.md` 复选框规则与 tests 相关断言同步
- **测试用例版本串陈旧**：`tests` 原「被测对象 v1.1.1」与包内 1.2.1 不一致；M2 / TC-01-03 还硬编码断言 version 为 `1.1.0` / `1.0.0`。统一改为与 SKILL.md 联动的 SemVer 一致性校验，并补「用例基线 v1.1.1、维护至 v1.2.2」说明
- **`## 目录结构` 与磁盘不一致**（约束 15）：SKILL.md / README.md 的目录树漏声明 `scripts/`，已补 `check_update.py` 与 `dep_lint.py`

## [1.2.0] - 2026-08-03

### 新增
