## 一、判定字段说明

| 字段 | 含义 | 判定标准 |
|---|---|---|
| **激活条件** | skill 是否被正确激活 | 收到 tri-intent 快照且 L2=I13 |
| **链路顺序** | 各阶段/审批门串行顺序 | 严格按门①→门②→门③，不可跳门 |
| **复选框状态** | 任务清单条目状态标记 | 默认 `- [ ] **完成状态**：未确认`（`- [ ]` 在行首）；完成指规划交付确认 |
| **方法论执行** | WBS+SMART 目标拆解方法论 | 每步完成标准满足 |
| **产物完整性** | 规划文档结构与落盘 | 3 个文档结构完整且落盘正确 |

## 二、评分规则

- 每条用例核心断言全部命中记 **PASS**，任一不符记 **FAIL**
- 通过率 = PASS 数 / 总用例数
- **质量门槛**：元数据/输入契约/职责边界场景 ≥95%，执行契约/审批门/交付产物场景 ≥90%，整体 ≥90% 视为达标

## 四、TC-02 强制执行契约验证（9 用例）

### TC-02-01：强制前置——收到快照且 L2=I13 时激活
- **前置条件**：tri-intent 产出快照，§三 结构化结论中 `intent.L2_核心意图=I13`，下游路由建议指向 tri-plan
- **测试步骤**：1. 模拟收到快照；2. 校验 skill 是否先读取 §三；3. 校验是否按规划工作流串行推进

- **通过标准**：PASS——先读 §三 再推进工作流；FAIL——跳过读取直接给计划

### TC-02-02：核心铁律——没有明确目标与验收标准就没有任务拆解
- **前置条件**：skill 已激活，进入阶段 1

### TC-02-03：三门串行规则（门①→门②→门③）

- **测试步骤**：1. 检查 SKILL.md 是否定义门①→门②→门③ 串行顺序；2. 模拟跳过门①直接产出 plan.md

- **通过标准**：PASS——声明协作且不越界规定实现细节；FAIL——未声明或越界规定代码细节

## 十、TC-08 质量标准验证（6 用例）

> 验证规划质量标准：任务可独立执行、验收标准可判定、依赖关系无环、风险有缓解措施、范围 MECE、SMART 目标校准。

### TC-08-01：任务可独立执行
- **前置条件**：plan.md WBS 分解已完成
- **测试步骤**：1. 检查每个叶子任务；2. 校验是否可独立分配执行
- **预期结果**：每个叶子任务可独立分配执行，不依赖同层其它任务的中间产物（检查无同层隐含依赖）
- **通过标准**：PASS——叶子任务均可独立执行；FAIL——存在同层隐含依赖

### TC-08-02：验收标准可判定
- **前置条件**：task-checklist.md 已产出
- **测试步骤**：1. 检查每个任务的验收标准；2. 校验是否含模糊词
- **预期结果**：每个任务有明确的完成判定条件，验收标准不含「大致」「尽量」等模糊词
- **通过标准**：PASS——验收标准明确无模糊词；FAIL——含模糊词或无判定条件

### TC-08-03：依赖关系无环
- **前置条件**：plan.md 依赖关系图已标注
- **测试步骤**：1. 检查依赖关系图；2. 执行拓扑排序校验
- **预期结果**：依赖图无循环，拓扑排序校验通过
- **通过标准**：PASS——拓扑排序通过无环；FAIL——检测到环

### TC-08-04：风险有缓解措施
- **前置条件**：plan.md 风险登记表已产出
- **测试步骤**：1. 检查风险登记表；2. 逐条核对缓解措施
- **预期结果**：每个风险都有缓解措施；高可能性+高影响的风险有应对策略（规避/转移/减轻/接受）
- **通过标准**：PASS——每个风险有缓解措施且高高有应对策略；FAIL——缓解措施缺失

### TC-08-05：范围无遗漏无重叠（MECE）
- **前置条件**：plan.md WBS 分解已完成
- **测试步骤**：1. 检查同层任务；2. 校验 MECE 原则
- **预期结果**：同层任务之和 = 父项全部范围，无遗漏无重叠（MECE）
- **通过标准**：PASS——MECE 满足；FAIL——有遗漏或重叠

### TC-08-06：SMART 目标校准
- **前置条件**：plan-brief.md 目标定义已完成
- **测试步骤**：1. 检查目标定义；2. 校验 SMART 5 维度校准
- **预期结果**：目标按 SMART 5 维度校准（Specific/Measurable/Achievable/Relevant/Time-bound）；目标含糊时在门①澄清
- **通过标准**：PASS——5 维度校准完成且目标不含糊；FAIL——维度缺失或目标含糊
