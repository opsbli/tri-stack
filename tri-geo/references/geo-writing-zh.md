# 中文可引用写作规范（geo-writing-zh.md）

> 加载时机：M3 内容重写 / M3+ 国内模型引用适配前（设计指南 §2.5）
> 校验执行：`scripts/writing_rules.py`（10 项检查）｜最后验证日期：2026-09-16

## 一、直答段规范（核心）

| 项目 | 规范值 | 说明 |
|------|--------|------|
| 位置 | 首段（标题之后第一段正文） | 前 120 字内 MUST 直接回答目标问题 |
| 字数 | **120-200 字**（初始工程值） | 中文信息密度高于英文，论文英文语料的 134-167 词不直接迁移 |
| 句式 | 定义句式优先：`X 是/指/包括 …` | 便于片段被独立抽取后仍自包含 |
| 必含 | 至少一个具体数字或可核验结论 | 无数字的直答段难以被引擎采信 |
| 禁用 | 以代词（它/该/这）开头；铺垫式开场 | 片段孤立抽取后丢失指代主体 |

**校准记录**（实测后更新，NEVER 凭感觉修改）：

| 日期 | 参数 | 原值 | 校准值 | 依据（实测证据路径） |
|------|------|------|--------|---------------------|
| 2026-09-16 | 直答段字数 | — | 120-200 字 | 初始工程值，待 T6 实测校准 |

## 二、证据密度配额

| 指标 | 配额 | 计入口径 |
|------|------|---------|
| 统计密度 | ≥3 个 / 500 字 | 百分比、金额（￥/$/万元/亿元）、年份、带单位数字（天/小时/倍/人/家/款/kg/GB/MB） |
| 外部引用 | ≥1 处 / 500 字 | 可访问 URL，且 URL 必须出现在数据句所在段落 |
| 具名来源 | ≥3 类 | 学术/官方/行业媒体/一手数据 |
| 专名 | 每块 ≥3 个 | 机构、产品、标准、算法等具名实体 |

每个数据句 MUST 附可核验来源（URL 或具名来源标记），`citation_check.py` 会拦截无来源数据句。

## 三、结构规范

1. 标题层级 H1 → H2 → H3 不跳级；信息型内容使用**问句式小标题**（什么是 / 如何 / 哪些 / 为什么 / 多久 / 多少钱）。
2. 比较类内容（≥3 项）用**表格**；流程类用**有序列表**；并列要点用**无序列表**。
3. 段落 2-4 句，单句不超过 60 字。
4. 每个小节自包含：重复主体名称，避免跨段指代。
5. 术语首次出现加粗或加《》，便于实体识别。

## 四、反模式（必删）

- 空话套话：随着…的发展 / 在当今… / 在这个信息爆炸的时代 / 众所周知 / 显而易见 / 不难看出 / 毋庸置疑 / 让我们一起 / 话不多说
- 空泛总结：总之 / 总而言之 / 综上所述（应替换为可引用的具体结论）
- 无信息量提示语：需要注意的是 / 值得注意的是
- 关键词堆砌：目标词出现频率 >1% 即触发负面信号（论文实证为负增益）
- 绝对化承诺与最高级用语（见 anti-patterns.md 广告法词表，红线）
