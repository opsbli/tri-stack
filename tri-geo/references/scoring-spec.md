# 双轨评分细则（scoring-spec.md）—— 唯一权威口径

> 脚本实现 MUST 与本文件一致；本文件变更 MUST 同步脚本注释与 CHANGELOG（设计指南 §6.3）
> 最后验证日期：2026-09-16

## 一、轨道 A：站内信号分（site_signal.py，确定性）

### 1.1 复合权重

| 维度 | 权重 | 说明 |
|------|------|------|
| 可引用性 citability | 40% | 五维加权（见 1.2） |
| 技术基建 infra | 20% | SSR 40% + 可索引 20% + 站点地图 20% + URL 10% + 语言 10% |
| 结构化数据 schema | 15% | JSON-LD 类型与必填字段 |
| 权威信号 authority | 15% | 署名 30 + 更新时间 25 + 外链 25 + 一手数据 20 |
| 爬虫与 llms.txt crawl_llms | 10% | 爬虫 70% + llms.txt 30% |

> 权重说明：设计指南 §4.1 未给出复合权重，此处按「删除海外 Platform 维度后重分配」固化；可引用性为 GEO 核心故取最大权重。

### 1.2 可引用性五维（块级，页面取 Top5 均值）

| 维度 | 权重 | 关键规则 |
|------|------|---------|
| 答案块质量 | 30% | 定义句式 30 + 首 60 字可独立成答 25 + 问句标题 20 + 短句占比 15 + 首句直接作答 10 |
| 段落自包含 | 25% | 字数 120-200（40）/100-250（28）/80-300（16）/其他（6）；代词密度 <2%（30）或 <4%（18）；专名 ≥3（30）或 ≥1（15） |
| 结构可读性 | 20% | 标题层级 30/12 + 列表或表格 25 + 句长可控 25/8 + 段落数 2-4（20） |
| 统计密度 | 15% | 每 500 字 ≥3 个统计点记满；按 `密度/3×100` 线性计分 |
| 独特性 | 10% | 原创研究句式 40 + 案例/样本 30 + 专有术语 30 |

### 1.3 技术基建判定

| 项 | 规则 |
|----|------|
| SSR | 正文 ≥800 字 100 / ≥300 字 70 / ≥100 字 40 / <100 字 0 |
| 可索引 | 标题与描述齐全 100 / 其一 60 / 均无 20 |
| 站点地图 | robots.txt 声明 Sitemap 100，否则 40 |
| URL | 无查询串且层级 ≤4 记 100，否则 60 |
| 语言 | lang 以 zh 开头 100，否则 60 |

### 1.4 爬虫与 llms.txt

- 参与判定的爬虫（公开 UA，verified）：Bytespider、Baiduspider、360Spider、Sogou web spider、YisouSpider。
- 未公开 UA 的厂商（DeepSeek/Kimi/智谱/元宝等）**不参与评分**，仅在报告中提示人工核查。
- 爬虫分 = 100 −（被禁已核验爬虫数 / 已核验爬虫总数）×100。
- llms.txt 分档：0（无）/30（有但格式不完整）/50（有标题与少量链接）/70（结构完整）/90（含 llms-full.txt）。

### 1.5 veto 一票否决

| code | 类型 | 触发 | 处置 |
|------|------|------|------|
| NO_CONTENT | block | 正文 <100 字 | 退出码 2，无法评分 |
| CRAWLER_BLOCKED_ALL | cap60 | 全部已核验爬虫被禁 | 总封顶 60，退出码 1 |

### 1.6 评级

90-100 优秀 ｜ 75-89 良好 ｜ 60-74 一般 ｜ 40-59 薄弱 ｜ 0-39 近乎不可见

## 二、轨道 B：引擎实测分（probe_runner.py + answer_judge.py）

| 项 | 规则 |
|----|------|
| prompt 集 | 覆盖品牌/对比/推荐/问题解决四意图，默认每引擎每问题 3 轮 |
| 提及判定 | 品牌名与别名的字符串匹配（大小写不敏感），附命中位置摘录 ±30 字 |
| 引用位次 | 按回答中出现的域名顺序取品牌域名首次序号（1 起）；无 URL 时取引用标记位置 |
| 情感 | 推荐/值得/稳定 → positive；不推荐/投诉/避坑 → negative；冲突 → conflict（标记存疑）；否则 neutral |
| 存疑样本 | 情感冲突或「有提及但无位次」→ 标记 `needs_llm_review`，NEVER 猜测判定 |
| 波动区间 | 由多轮采样实测的 min/max 统计得出，**不预设数值** |
| 缺失数据 | 引擎不可达 → `source_type: trace_search/unavailable` 并显式标注；样本为空 NEVER 记 0 分 |

## 三、评分来源规范（P3）

每个对外分数 MUST 呈现：分数 ｜ 产出脚本 ｜ 证据路径 ｜（实测）采样轮数与波动区间 ｜（文献）来源与测试环境。转引未核验数字不得用于评分。

## 四、失败与降级

| 情形 | 处置 |
|------|------|
| 抓取失败（重试 2 次） | 报错，建议用户粘贴正文，NEVER 伪造内容块 |
| 单轮实测失败 | 重试 1 次；有效轮数 <2 标注「样本不足」 |
| 判定规则不确定 | 标记 needs_llm_review；兜底占比 >30% 必须补规则 |
| 快照写入失败 | 输出 JSON 请用户手动保存 |
| 报告渲染失败 | 降级 Markdown |
