# GEO 理论基线（中国市场视角）

> 最后验证日期：2026-09-16 ｜ 状态：理论部分为公开学术成果（可溯源）；国内引擎适配部分标 `unverified` 待实测
> 本文件由 M1-M6 全流程启动前加载（设计指南 §2.5）

## 一、定义与范式转变

GEO（Generative Engine Optimization，生成式引擎优化）：通过系统性调整内容的结构、语义、可信度与呈现方式，提升内容在生成式引擎回答中的**被引用概率、提及频率与呈现位置**。

| 维度 | SEO | GEO |
|------|-----|-----|
| 引擎机制 | 检索 → 排序 → 用户点击 | 检索 → 阅读理解 → 多源合成 → 带引用作答 |
| 优化对象 | 爬虫的排序规则 | 模型的理解力与引用选择 |
| 胜利标准 | 排名第一 → 获得点击 | 被模型选为答案素材 → 获得引用 |
| 度量口径 | SERP 排名、CTR | PAWC、引用份额（Citation Share）、提示词份额（Share of Model） |
| 流量结构 | 点击链接进入网站 | AI 合成答案直接满足需求，点击必要性下降（定性趋势） |

## 三、国内引用生态（定性方向，`status: unverified`）

以下为单源行业报道的定性方向，**未独立核验**，仅用于生成假设与实测 prompt 设计，**不得作为评分或结论输出**：

| 引擎 | 报道中的信源偏好（待实测） | 状态 |
|------|--------------------------|------|
| 豆包 | 优先字节系内容（头条/抖音）与 CSDN | unverified |
| 元宝 | 重度依赖微信公众号生态 | unverified |
| 百度 AI 搜索 | 首选百家号 | unverified |
| DeepSeek / Kimi | 引用知乎、搜狐等开放社区与门户 | unverified |
| 智谱 GLM / 通义 / 文心 | 未获取可靠公开数据 | unverified |

**校准路径**：用 `probe_runner.py plan` 生成 prompt 集 → Agent 实际提问并 `ingest` 回填原始回答 → `answer_judge.py` 规则判定 → 以实测来源分布回写本表并把状态改为 `verified(日期)`。

## 四、评分引用规范（P3，四规则）

1. 对外呈现的每个分数必须由确定性脚本计算产生，并落盘原始证据（HTML 输入、引擎原始回答、判定 JSON）。
2. 引用文献中的实验数字必须注明测试环境与数据来源；转引未经独立核验的数字必须显式标注"转引未核验"，且不得用于评分。
3. 实测分数必须标注采样轮数与波动区间；区间由实测多轮采样统计得出，**不预设数值**（明确不沿用竞品的 ±8% 假设）。
4. 无法实测验证的内容不得以"评分"形式呈现，只能以定性描述呈现并标注依据类型。

## 五、红线：禁捏造

- 伪造引文/数据曾在早期实验中提升可见度，但已有研究（StealthRank 2025、C-SEO Bench NeurIPS 2025，**均为转引未核验**）表明其正被引擎作为对抗信号训练，且竞争环境下增益蒸发。
- 法律与合规风险：YMYL 领域资质要求、广告法禁用语、虚假宣传责任。
- 落地方式：`citation_check.py` 命中即**硬阻断**（退出码 3），NEVER 降级、NEVER 豁免；`writing_rules.py` 过滤广告法禁用语（红线，退出码 3）。
