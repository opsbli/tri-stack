# 反模式与反操纵自检（anti-patterns.md）

> 词表与 `scripts/writing_rules.py` 保持一致：修改词表 MUST 同步脚本与 CHANGELOG
> 最后验证日期：2026-09-16

## 一、写作反模式（R8，脚本正则）

| 类别 | 词/句式 | 问题 |
|------|---------|------|
| 套话开场 | 随着…的发展 / 在当今… / 在这个信息爆炸的时代 | 无信息量，占用首段位置（首段应直答） |
| 无信息量过渡 | 众所周知 / 显而易见 / 不难看出 / 毋庸置疑 | 无证据支撑 |
| 口语化开场 | 让我们一起 / 话不多说 / 直接进入正题 | 降低可被抽取的密度 |
| 空泛总结 | 总之 / 总而言之 / 综上所述 | 应替换为可引用结论 |
| 无信息量提示 | 需要注意的是 / 值得注意的是 | 同上 |

## 二、广告法禁用语（R9，红线，命中即打回）

| 类别 | 示例 |
|------|------|
| 绝对化「最」 | 最好 / 最佳 / 最优 / 最强 / 最先进 / 最专业 |
| 极/顶级 | 最高级 / 极品 / 极致 / 顶级 / 顶尖 |
| 「第一」类 | 第一品牌 / 全国第一 / 行业第一 / 排名第一 / 销量第一 |
| 权威化 | 国家级 / 世界级 / 国际级 |
| 唯一/首选 | 首选 / 独一无二 / 绝无仅有 / 史无前例 |
| 绝对化承诺 | 绝对 / 百分之百 / 100%有效 / 百分百 |
| 永久/根治 | 永久 / 彻底治愈 / 根治 / 包治 |

> 注意：词表刻意不捕获「第一步」「第一层」等顺序用法，避免误杀；描述性语句若含上述词仍会命中，此时应改写表述（如「排名第一获得点击」→「排名靠前获得点击」）。

## 三、GEO 反操纵自检（发布前必查）

1. **关键词堆砌**：目标词词频 >1% → 论文实证为负增益，立即降频。
2. **无来源数字**：任何百分比/金额/年份类数据句未附来源 → `citation_check.py` 阻断。
3. **虚假权威**：未具名的「专家表示」「权威机构」→ 需替换为可核验对象或直接删除。
4. **跨页自相矛盾**：同一事实在不同页面表述不一致 → 降低被引擎采信的概率。
5. **过期内容**：`dateModified` 与正文数据年份长期未更新 → 时效信号衰减。
6. **过度优化痕迹**：同一品牌词在单段重复 3 次以上、为凑密度插入无关数字 → 删除。
7. **结构伪装**：为抽取而拆分出的无意义短句（碎片化）→ 合并为自包含直答段。

## 四、合规边界

- 医疗/金融/法律等 YMYL 内容：需资质作者署名与免责声明，否则 veto 封顶。
- 数据引用须注明来源与统计口径；不得截断引用造成语义反转。
- 不得为提升可见度而批量生成同质化内容（可能被判重复内容降权）。
