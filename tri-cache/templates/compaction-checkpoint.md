# 上下文压缩检查点 · <会话ID>_<序号>

> 用途：替换被压缩掉的较早对话，使压缩后的历史仍是合法输入且不丢状态。
> 纪律：逐项枚举不合并、关键值逐字保留、凭据仅留占位+取值位置指针、不发明内容。

| 字段 | 值 |
|---|---|
| 会话 ID | <会话ID> |
| 序号 | <第 N 次压缩> |
| 压缩触发 | <溢出信号 命中 / 用户显式请求> |
| 被压缩范围 | <第 X 轮 ~ 第 Y 轮> |
| 保留原文轮数 | <最近 N 轮> |
| complete | <true \| false>（被预算截断 MUST 为 false） |
| 截断原因 | <若 false 则说明原因> |
| 生成时间 | <YYYY-MM-DD HH:MM:SS> |

## 一、目标

> 本次会话/任务的总体目标与当前范围（一句话 + 边界）。

<目标与边界>

## 二、已确认项

> 逐条列举，一条一行，禁止合并、禁止「等 N 项」。每条给出证据位置。

- [x] <已确认的结论 1> — 证据：<file:line / 命令+退出码 / 文档条目>
- [x] <已确认的结论 2> — 证据：<...>

## 三、未决项

> 尚未确认也未能排除的项；每条写明卡点。

- [ ] <未决项 1> — 卡点：<上下文截断 / 工具不可用 / 信息缺失>
- [ ] <未决项 2> — 卡点：<...>

## 四、关键值原文

> 逐字保留，不改写、不占位、不 paraphrase。这些是不可再生的信息。

| 类别 | 值（原文） | 出处 |
|---|---|---|
| URL / 端点 | <原文> | <位置> |
| 文件路径 | <原文> | <位置> |
| 参数 / payload | <原文> | <位置> |
| 版本 / 错误原文 | <原文> | <位置> |
| token / 凭据 | `<脱敏占位>` — 取值位置：<file:line 或 env 名> | <位置> |

> 走过的路也值钱：记录尝试过的方法与结果，避免压缩后重复踩坑。

| 尝试 | 结果 | 证据 |
|---|---|---|
