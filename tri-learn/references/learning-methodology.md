# tri-learn 学习方法论细化

> 本文件是 `SKILL.md`「学习方法论」章节的细化参考（常驻层）。正文只留概览与指针，本文件承载教学规则的完整展开、反模式边界与决策逐条可回溯依据。

## 一、三条教学原则（全场景）

| 原则 | 展开 | 触发标识 |
|---|---|---|
| 费曼技巧 | 用最简单语言解释复杂概念，多用类比、真实场景、学习者熟悉的例子 | 任何内容讲解 |
| 苏格拉底式提问 | 不急着给答案，用追问引导学习者自己推导、澄清、修正 | 回答有偏差/疑问 |
| 脚手架原则 | 从学习者已知出发，一步一台阶，每步接住前一步 | 新概念引入 |

底线：**鼓励犯错**。错误是判断理解深度的诊断信号，NEVER 批评学习者。情绪基调始终为「鼓励」。

## 二、五入口 + 答站（流程路由细表）

| 信号 | 流程 | 必做动作 |
|---|---|---|
| 学/教/带我学 X | 学习模式 | 新主题三问评估 → 建目录 → 生成本课 → 检查站收尾 |
| 我想复习 / 复习 X | 复习模式 | 读三文件 → 算天数 → 找到期项 → 主动回忆开场 |
| 今天该复习什么 | 全局复习模式 | 扫所有主题复习计划 → 三档分组（expired/today/next3） |
| 看看我的错题 / 遗漏 | 错题模式 | 汇总活跃遗漏 → 与学习者确认 → 更新解决证据 |
| 多久没学 X | 间隔查询 | 读进度.md 最后学习日期 → 算天数 |
| 提交检查站答案 | 回答判掌握 | 查掌握矩阵 → 写回三文件 → 决定下一步 |

## 三、掌握判断矩阵（决策 IF-THEN 逐条）

| 程度 | 学习信号判断 | 决策动作 | 是否推进下一课 |
|---|---|---|---|
| 完全掌握 | 答案准确，能举一反三 | 标记掌握，写复习计划，生成下一课 | 是 |
| 基本掌握 | 大致正确，有小偏差 | 简短纠正，记录小遗漏，写复习计划，生成下一课 | 是 |
| 部分理解 | 概念混淆，说不出为什么 | 记录遗漏，生成 NNb_补充.md | 否 |
| 尚未理解 | 答案错误或不知道 | 记录卡点，苏格拉底追问，从更基础处重建 | 否 |

> **铁律**：未掌握切片（部分理解/尚未理解）NEVER 推进下一课；NEVER 因进度、时间、礼貌而降低判断标准。

## 四、反模式（失效区，NEVER 触发）

- 一次性生成全部课程（违「掌握推进」）。
- 当前课未掌握就生成下一课（违铁律）。
- 复习时先让学习者重读原文，而非主动回忆（违防泄题）。
- 复习日期用「三天后」等相对时间（违绝对日期）。
- 把学习记录全都塞进一个 `进度.md`，破坏自动可检索（违文件契约）。
- 对医学/法律/金融等高风险主题给出专业处方建议。
- 知识锚点无可靠来源却编造出处（违守真）。

## 五、新手常见失误

- 不建固定文件名（`进度.md`等被改名/漏建）导致后续复习无法定位。
- 新主题没做三问起点评估就开讲。
- 不等待学习者回答检查站就推进。
- 复习开场直接泄答案而非追问。

## 六、适用边界

- 仅适用可结构化、可分步、可设检查站的技能/知识类学习。
- 不适用纯动手实操（无问答闭环）或一次性资料阅读场景。
- 高风险主题只做概念学习，MUST 提醒咨询专业人士。

## 七、经验沉淀位（进化契约联动）

每次实际教学暴露的遗漏、反模式教训，追加到「四、反模式」下方并注明日期与触发场景；同一失误重复 2 次以上时，向上修订 SKILL.md 流程描述并联动更新版本号三件套。
