# 保真度分级规范（tri-html2md 唯一事实源）

> 本文件把用户的「高质量无损转化」诉求落为**可验证的分级保真**。置信度阈值、关键数据口径的唯一真源；`scripts/quality_check.py` 是其可执行实现。
> **grep 检索模式**：按阈值 `grep -n "置信度"`；按指标 `grep -n "文本召回率|丢失率|噪声率"`；按复核 `grep -n "复核项"`。

---

## 一、诚实声明（契约固定文案，报告必带）

> HTML 是富文本标记语言：内含内联样式/脚本/富交互/嵌套结构，而 Markdown 是纯文本标记。HTML→MD 本质是**结构降维而非格式复制**。本 skill 承诺的是「可验证的分级保真」——文本召回率/丢失率可计算、置信度可分级、复核项可执行——NEVER 承诺绝对无损。

**理论上不可无损的维度**（结构性限制，任何工具相同）：内联样式（style 属性/class 视觉样式）、脚本与富交互（JS 行为）、嵌套表格（层级压平）、相对链接（路径失效）。
**可高质量的维度**：可见文本（召回 ≥95% 可达）、标题层级（h1-h6 → # 语法）、表格（pandoc GFM 输出 TEDS 高）、图片/链接引用（保留 src/href）。

## 二、关键数据口径（用户硬要求：报告 MUST 告知）

| 关键数据 | 口径定义 | 计算实现 |
|---|---|---|
| **文本召回率** | HTML 可见文本（跳过 script/style）归一化字符 bigram 被 MD 覆盖的比例 | `quality_check.py` `compute_metrics()` |
| **丢失率** | 1 − 文本召回率 | 同上 `loss_rate` |
| 噪声率 | MD 归一化 bigram 不在 HTML 可见文本中的比例（脚本残留/幻觉信号） | 同上 `noise_rate` |
| 结构对比 | 标题 h1-h6/表格/图片/链接：HTML 侧标签计数 vs MD 侧语法计数 | `HtmlTextExtractor` 计数 vs 正则计数 |
| 置信度等级 | A/B/C，判定见 §三 | `grade_confidence()` |
| 转换元数据 | 后端/档位/文件大小/耗时/资产数/降级轨迹 | 门A/B/C 过程数据 |
| 异常清单 | 乱码 U+FFFD/编码误判特征/空 MD/截断（<30%）/围栏不成对/脚本泄漏 | 正则 + 启发式 |

**归一化规则**（跨格式公平比较）：仅保留字母（小写化）+ 数字 + CJK 字符，其余剔除；按字符 bigram 集合求交。**HTML 无可见文本（可见文本 <50 字符）**：召回率/丢失率显式标注「不适用（无可见文本）」，置信度直接 C 级口径，NEVER 编造数值。

---

## 三、置信度分级阈值（唯一真源）

| 置信度 | 判定标准 | 处置 |
|---|---|---|
| **A 直接可用** | 文本召回率 ≥ **95%** 且结构计数吻合且无异常 | 交付，报告标注；固定复核项仍列出 |
| **B 抽查复核** | 文本召回率 **85–95%**，或 HTML 有图片/链接而 MD 无对应引用 | 交付 + 列出复核项 |
| **C 强制人工复核** | 文本召回率 < **85%**，或检出乱码/编码误判/脚本泄漏/空输出，或召回率无法计算 | 交付 + 醒目警示 + 建议升级档位重转（沿降级链反向：L0→L1） |

**降级/升级判定**（阈值联动 `detect_backends.py` GRADE_ORDER）：C 级报告 + 用户要求重转 → 建议升档（L0 结果差 → 试 L1）；L1 后端执行失败 → 沿链降档重试。

## 四、固定复核项清单（永不消失，即使 A 级）

report.md MUST 固定列出，用户复核后回填「复核结果回填」段（反哺进化契约）：

1. 内联样式丢失（style 属性/class 样式在 MD 中不可见，确认无关键信息依赖样式）
2. script/style 内容误入正文（确认脚本/样式未泄漏进正文）
3. 相对链接失效（相对路径在 MD 中可能失效，确认引用完整性）
4. 嵌套表格（HTML 嵌套表格转 MD 后可能被压平，确认结构）
5. 编码误判（gbk 中文乱码，确认无 U+FFFD/锟斤拷）

## 质量四维抽评（可选 · P2-1 · 默认关闭）

> 方法论蒸馏自 anydoc 基准四维盲评（completeness / structure / formatting / cleanliness，LLM-judge 双 swap 交叉）——蒸馏报告 docs/distill-anydoc-main-20260908.md P2-1。本节是 SKILL.md 门D「质量四维 LLM 抽评」的唯一真源。

| 维度 | 定义 | 典型扣分点 |
|---|---|---|
| completeness 完整性 | 源信息是否全部进入 MD（文本/表格/列表/脚注/图片引用） | 段落遗漏、表尾截断、脚注丢失 |
| structure 结构性 | 标题层级/列表嵌套/表格网格是否与源一致 | 层级压平、列错位、嵌套丢失 |
| formatting 格式保真 | 加粗/斜体/代码/链接/公式 LaTeX 是否保真 | 样式丢失、锚点断裂、公式乱码 |
| cleanliness 洁净度 | 噪声率：残留标签/冗余空行/转换伪影 | HTML 残留、重复页眉、乱码 U+FFFD |

执行规则：

1. **默认关闭**：确定性指标（保真率/丢失率/结构对比/置信度）已交付时，NEVER 自动附加本抽评。
2. **启用 = 付费确认场景（总则②）**：MUST 用户显式二次确认后才执行；执行前告知额外成本。
3. **盲评双 swap**：四维各 1–5 分；两名 judge 独立评（顺序互换 A/B），分差 ≥2 的维度 MUST 标注「分歧」并列入人工复核项。
4. **抽样**：文档 ≤10 页全量；>10 页按标题分层抽样（≥3 层、每层 ≥1 块、总量 ≤10 块）。
5. **结果落盘**：report.md 追加「质量四维抽评」段（四维得分/分歧项/抽样清单/基准来源标注）；基准引用一律标注出处，NEVER 裸引数字。

## 五、修订规则

- 阈值调整只改本文件 §三 + `quality_check.py` 顶部常量（两处 MUST 同步，CHANGELOG 记录）。
- 触发修订的条件（进化契约）：同类 HTML 连续 ≥3 次 C 级；后端能力排名显著变化；新复核项被用户回填确认。
