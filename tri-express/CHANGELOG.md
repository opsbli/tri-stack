# Changelog

本文件记录 tri-express skill 的版本变更历史。

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。


## [1.2.0] - 2026-08-03

### 新增

- **版本检查与更新机制**：新增「版本检查与更新机制」独立章节，作为 skill 任一执行入口启动后的第零步。包含：
  - 设计原则与触发时机：版本检查 → 上游依赖检测 → 读取快照 → 核心执行 的执行顺序固化
  - 版本检查技术实现标准：校验端点、请求载荷、响应契约、SemVer 比较、超时控制（≤5s）、幂等性
  - 更新流程安全验证要求：来源校验（官方通道 ONLY）、SHA-256 完整性校验、签名校验、回滚保障、权限最小化、版本一致性联动
  - 六类禁止执行判定条件（P1–P6）及结构化阻断提示
  - mermaid 流程图展示完整决策链路
- **强制执行契约第 0 条（版本检查前置硬门）**：优先级高于所有其他强制前置条目，明确版本检查为执行流程第零步，更新完成前 NEVER 进入后续步骤

### 变更

- frontmatter version `1.1.1` → `1.2.0`

## [1.1.1] - 2026-08-02

### 修复

- 在「强制执行契约」后补充 I19 兜底层级澄清：I19 属 Expressing 类兜底（闲聊/陪伴），与 tri-intent 的 Doing 类低置信回退分属不同层，不竞争；仅在无明确 B.Doing/A.Asking 意图时触发。
- 「目录结构」补全 README.md / CHANGELOG.md / tests/，与实际文件树一致。
- 本版本无功能变更，仅契约澄清与文档合规修正（PATCH）。

## [1.1.0] - 2026-07-26

### 新增

- 上游依赖检测两态逻辑（标准模式/引导安装），支持独立安装
- 独立使用时检测 tri-intent 是否可用，未检测到则引导安装

### 变更

- 明确不支持降级模式——引导安装为硬性阻断

## [1.0.0] - 2026-07-24

### 新增

- 初始版本：处理 I17–I20 表达陪伴类意图
- 4 子意图差异化回应基调（角色扮演/情感陪伴/闲聊娱乐/观点表达）
- 安全边界优先机制（安全边界优先于人设维持）
- 不落盘不产出文件，与 tri-intent 的「不落盘」Flow 一致
- 无自检句要求，保持对话自然度
- 轻量无审批门
