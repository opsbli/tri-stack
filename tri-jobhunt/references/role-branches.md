# 专项角色分支（role-branches）· 共享资源层

> 由 ResumeSkills-main 的 tech / executive / academic / creative / career-changer 五个角色技能蒸馏。
> 五角色**不是独立方法论**，而是「通用求职方法论 × 特定受众口味」的组合——本文件只记录**角色差异增量**，
> 通用规则（ATS / 量化 / STAR）一律引用共享层。供 tri-role 子 skill 叠加使用。
> grep 模式：`技术` / `高管` / `学术` / `创意` / `转行`

## 一、技术（Tech）

- 章节顺序：`Contact(含 GitHub) → Summary → Technical Skills → Experience → Projects → Education → Certifications`。
- 技术技能三式：By Category / By Proficiency / Flat List。
- 技术 Bullet 公式：`[Action Verb] + [Technical What] + [Scale/Impact] + [Technology Used]`。
- 技术指标四类：Scale / Performance / Efficiency / Business。
- Projects 规则：有真实用户 / 开源 / hackathon；GitHub Profile 一并优化。
- 边界：Bootcamp / 自学 / 栈不匹配时，强调迁移技能 + 学习速度。

## 二、高管（Executive）

- 页数：VP 2 页 / C-Suite 2-3 / Board 可更长。
- 7 节结构：`Executive Profile → Core Competencies(领导主题) → Career Highlights → Experience → Board & Advisory → Education & Development → Recognition`。
- Bullet 公式：`[Leadership Action] + [Strategic Initiative] + [Business Outcome at Scale]`。
- 转型故事公式：`Inherited [情境]. Implemented [方案]. Achieved [结果].`。
- 每经验必含：公司上下文 + 汇报结构 + P&L（损益）+ 战略范围。
- 用权力动词（Spearheaded / Orchestrated / Championed / Steered）；避免战术动词 / I 人称 / 无下文行话。
- 机密数据用百分比 / 范围 / 相对影响替代绝对数；按猎头 / 董事会 / PE-VC 受众调整。

## 三、学术（Academic / CV）

- CV 2-20+ 页随生涯增长，**不可人为限制**；`Resume vs CV` 区分（CV=综合记录+专业术语）。
- 12 节标准顺序：`Contact/Education/Positions/Publications/Presentations/Grants/Teaching/Mentoring/Service/Memberships/Awards/References`。
- 章节顺序随职位变：研究岗 Publications 先行 / 教学岗 Teaching 先行 / 行政岗 Service 先行。
- 长度按阶段：Graduate 2-4 / Postdoc 3-6 / Early 5-10 / Mid 10-20 / Senior 15-30+ 页。
- Publications 格式：编号或分类列表，作者加粗、DOI、学生合著加 `*`。
- 学科惯例：Sciences（作者顺序/影响因子/编号）；Humanities（单著重要/书籍关键）；Social Sciences（个人+合作/政策影响）。
- 资助三分：Awarded / Pending / Not Funded（可选）；CV 无未解释空白；**6 个月内更新**。

## 四、创意（Creative / 作品集）

- **两版本方法**：ATS 版（在线申请）+ 设计版（作品集 / 网络 / 直投）。
- ATS 安全创意元素：留白 / 文字层级 / 组织 / 文案；禁多列 / 文本框 / 图片 / 表格。
- 设计三原则：Show > Tell、Clarity > Cleverness、Brand Consistency。
- 规格：≤2 字体族、2-3 色、B&W 打印友好、**6 秒可扫描**。
- 细分：Graphic / UX / Marketing / Writer / Photographer；工具 InDesign / Figma / Canva，避 PowerPoint / 在线模板。

## 五、转行（Career Changer）

- 四大迁移技能框架：Leadership / Communication / Analytical / Technical-Operational。
- 术语翻译：把原行业语言映射到目标行业（每个转行路径给术语对照）。
- 三步骤：Lead with Transferable Summary → Functional/Hybrid 格式 → Bridge Experiences。
- "Why" 叙事四段：DISCOVERY → CONNECTION → ACTION → VISION。
- 转行理由须为**兴趣进化**，禁「burned out / hate current job / more money」。
- 行业路径：Into Tech / Into Finance / Into Healthcare（各给切入点 + 桥梁活动）。
