# 保真度分级规范（tri-docx2md 唯一事实源）

> 本文件把用户的「高质量无损转化」诉求落为**可验证的分级保真**。置信度阈值、关键数据口径的唯一真源；`scripts/quality_check.py` 是其可执行实现。
> **grep 检索模式**：按阈值 `grep -n "置信度"`；按指标 `grep -n "保真率|丢失率|噪声率"`；按复核 `grep -n "复核项"`。

---

## 一、诚实声明（契约固定文案，报告必带）

> Word→MD 是「结构降维」：OOXML 内含段落/标题/表格语义可保留，但**批注、修订痕迹、页眉页脚、嵌入对象（OLE）在 Markdown 中必然丢失**。本 skill 承诺的是「可验证的分级保真」——保真率/丢失率可计算、置信度可分级、复核项可执行——NEVER 承诺绝对无损。

**理论上不可无损的维度**（结构性限制，任何工具相同）：批注与修订（MD 无对应语法）、页眉页脚（可能并入正文或丢失）、嵌入对象（OLE 仅保留占位或丢失）、中文字体嵌入缺失、嵌套表格（MD 表格语法不支持嵌套，被压平）。
**可高质量的维度**：正文文本（召回 ≥95% 可达）、标题层级（Heading 样式 → MD 标题）、简单表格（→ MD 表格）、图片（提取为 assets/ 引用）。

---

## 二、关键数据口径（用户硬要求：报告 MUST 告知）

| 关键数据 | 口径定义 | 计算实现 |
|---|---|---|
| **保真率（文本召回率）** | 源文档提取文本归一化字符 bigram 被 MD 覆盖的比例 | `quality_check.py` `compute_metrics()` |
| **丢失率** | 1 − 保真率 | 同上 |
| 噪声率 | MD 归一化 bigram 不在源文档中的比例（幻觉/冗余信号） | 同上 `noise_rate` |
| 结构对比 | 标题/表格/图片：源侧计数 vs MD 侧语法计数 | `count_source_structure()` |
| 置信度等级 | A/B/C，判定见 §三 | `grade_confidence()` |
| 转换元数据 | 后端/档位/耗时/资产数/降级轨迹 | 门A/B/C 过程数据 |
| 异常清单 | 乱码 U+FFFD/空 MD/截断（<30%）/围栏不成对 | 正则 + 启发式 |

**归一化规则**（跨格式公平比较）：仅保留字母（小写化）+ 数字 + CJK 字符，其余剔除；按字符 bigram 集合求交。**源文本不可提取（<50 字符）**：召回率/丢失率显式标注「不适用（源文本不可提取）」，置信度直接 C 级口径，NEVER 编造数值。

**源文本提取链**：python-docx（段落+表格单元格）→ mammoth `extract_raw_text` → zipfile 解 `word/document.xml` 剥标签。`.doc` 旧格式源侧计数不可直接计算（python-docx 不读 OLE），以中间转换后的 docx 为源侧口径并标注。

## 三、置信度分级阈值（唯一真源）

| 置信度 | 判定标准 | 处置 |
|---|---|---|
| **A 直接可用** | 保真率 ≥ **95%** 且结构计数吻合且无异常 | 交付，报告标注；固定复核项仍列出 |
| **B 抽查复核** | 保真率 **85–95%**，或源文档有图片而 MD 无图片引用 | 交付 + 列出复核项 |
| **C 强制人工复核** | 保真率 < **85%**，或检出乱码/截断/表格丢失，或召回率无法计算 | 交付 + 醒目警示 + 建议升级档位重转（沿降级链反向：L0→L1） |

**降级/升级判定**（阈值联动 `detect_backends.py` GRADE_ORDER）：C 级报告 + 用户要求重转 → 建议升档（L0 结果差 → 试 L1 pandoc）；L1 后端执行失败 → 沿链降档重试。

## 四、固定复核项清单（永不消失，即使 A 级）

report.md MUST 固定列出，用户复核后回填「复核结果回填」段（反哺进化契约）：

1. 批注与修订丢失（Word 批注/修订痕迹在 MD 中必然不呈现）
2. 页眉页脚（页眉页脚内容可能被并入正文或丢失）
3. 嵌入对象（OLE 嵌入对象/图表仅保留占位或丢失）
4. 中文字体（字体嵌入缺失导致的字符/样式差异）
5. .doc 旧格式兼容（LibreOffice 中间转换的版式漂移）
6. 表格嵌套（嵌套表格在 MD 中可能被压平）

## 四·补、元素级复核项（P1-3，2026-09-08 增补 · 来源：anydoc-main 蒸馏报告 v1.3.0 元素×skill 能力矩阵）

| 元素 | 计数指标（quality_check.py 输出） | 复核规则（确定性） |
|---|---|---|
| 公式（OMML→LaTeX） | `elem_formulas` | 源侧 OMML 计数 > 0 且 MD 侧为 0 → 复核项「公式丢失」 |
| 脚注/尾注 | `elem_footnotes` | `[^N]` 引用与定义不成对 → 复核项 |
| 内链锚点 | `elem_anchor_refs` | `[](#...)` 死链扫描（引用存在但锚点被删）→ 复核项 |
| 任务列表 | `elem_task_items` | 源 checkbox 计数 vs `[x]/[ ]` 计数不一致 → 复核项 |
| 图表/SmartArt | `md_tables` 增量 + assets | anydoc 主链应文本化（题注+数据表）；仅图片资产 → 复核降级链是否生效 |

> 落点说明：OOXML 兼容性（mc:AlternateContent/域指令）属解析器内部行为，由 anydoc 前端保证，不占本清单行；嵌入资产由 `dump_assets.py` 承接（P0-4）。


## 质量四维抽评（可选 · P2-1 · 默认关闭）

> 方法论蒸馏自 anydoc 基准四维盲评（completeness / structure / formatting / cleanliness，LLM-judge 双 swap 交叉）——蒸馏报告 docs/distill-anydoc-main-20260908.md P2-1。本节是 SKILL.md 门D「质量四维 LLM 抽评」的唯一真源。

| 维度 | 定义 | 典型扣分点 |
|---|---|---|
| completeness 完整性 | 源信息是否全部进入 MD（文本/表格/列表/脚注/图片引用） | 段落遗漏、表尾截断、脚注丢失 |
| structure 结构性 | 标题层级/列表嵌套/表格网格是否与源一致 | 层级压平、列错位、嵌套丢失 |
| formatting 格式保真 | 加粗/斜体/代码/链接/公式 LaTeX 是否保真 | 样式丢失、锚点断裂、公式乱码 |
| cleanliness 洁净度 | 噪声率：残留标签/冗余空行/转换伪影 | HTML 残留、重复页眉、乱码 U+FFFD |

执行规则：

1. **默认关闭**：确定性指标（保真率/丢失率/结构对比/置信度）已交付时，NEVER 自动附加本抽评。
2. **启用 = 付费确认场景（总则②）**：MUST 用户显式二次确认后才执行；执行前告知额外成本。
3. **盲评双 swap**：四维各 1–5 分；两名 judge 独立评（顺序互换 A/B），分差 ≥2 的维度 MUST 标注「分歧」并列入人工复核项。
4. **抽样**：文档 ≤10 页全量；>10 页按标题分层抽样（≥3 层、每层 ≥1 块、总量 ≤10 块）。
5. **结果落盘**：report.md 追加「质量四维抽评」段（四维得分/分歧项/抽样清单/基准来源标注）；基准引用一律标注出处，NEVER 裸引数字。

## 五、修订规则

- 阈值调整只改本文件 §三 + `quality_check.py` 顶部常量（两处 MUST 同步，CHANGELOG 记录）。
- 触发修订的条件（进化契约）：同类 Word 连续 ≥3 次 C 级；后端排名显著变化；新复核项被用户回填确认。
