# I01 信息查询（Asking）

## 识别特征

- 疑问词以 **What / Who / When / Where / How much** 为主
- 期望答案是**可核实的客观事实**：数字、日期、名称、状态、清单
- 无需推理链，答案有明确正误
- 典型语料：「Taro 最新稳定版是多少」「某公司 CEO 是谁」「北京今天限行尾号」

## 与邻近意图边界

- vs **I02 概念解释**：I01 要「事实点」，I02 要「原理与来龙去脉」
- vs **I05 推理计算**：I01 直接可查，I05 需多步推导
- 若答案随时间变化（新闻/价格/版本）→ 必须走实时检索，标注时效
