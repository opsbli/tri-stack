# M05 中止确认（Meta · 流程控制信号）

## 识别特征

- **极短的控制指令**，针对当前/待办动作
- 中止类：**停 / 别做了 / 取消 / 先等等 / 不用了 / 撤回**
- 确认类：**可以 / 确认 / 就这样 / 继续 / 批准 / 没问题**
- 不含新的任务内容，只表态放行或叫停

## 与邻近意图边界

- vs **M02 纠错反馈**：M02 指出错误并要求重做，M05 只叫停/放行不给修改方向
- vs **M03 追加细化**：M03 补充新要求继续做，M05 无新增内容
- vs **I19 闲聊**：M05 指向明确的执行动作，非无目的对话
