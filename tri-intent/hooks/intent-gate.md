# 意图识别结果呈现器（intent-gate）

> **定位**：意图识别产出快照后的**可选**复述工具。位于「产出快照」之后、「交接下游 skill」之前。
> **目标**：用轻量复述让用户发现明显误识别，并给出下游 skill 路由建议。不编排执行，不设审批门。

## 触发时机

```
意图识别 → 产出快照 snapshot.md → 【可选调用 intent-gate 复述】 → 交接下游 skill
```

> 复述是**可选**的。当 clarify-gate 已完成澄清、需求已充分时，连这一次复述都可跳过。

## 工具行为

### 1. 轻量复述（读取快照渲染给用户）

```text
# ===== 意图识别结果（可选轻量复述）=====
【我理解你要】：<快照 §三 一句话复述>
【意图类型】：<L1 交互类型> / <L2 核心意图编码+名称>
【任务要点】：
  1. <任务要点 1>
  2. <任务要点 2>
【下游路由】：<基于 L2 意图的下游 skill 路由建议>
【落盘去向】：<落盘快照 | 不落盘 | 先澄清>

如发现明显误识别，请指出，我将更新快照。
如理解正确，无需回复——快照已交接下游 skill 处理。
# ======================================
```

### 2. 落盘去向与路由

| 用户反应 | 工具行为 |
|---|---|
| 指出误识别 | 更新快照中的结构化结论，无需多轮审批循环 |
| 无反馈/确认正确 | 快照已交接下游 skill，无需等待 |
| 未调用本工具 | 快照直接交接下游 skill |

### 3. 闭环规则

- **快照永不覆盖**：用户指出误识别时，在原快照追加「修正」段落，保留完整溯源链
- **不设审批门**：复述仅供发现明显误识别，不构成执行前置审批
- **不编排下游**：本工具不决定下游 skill 如何执行（产出何种文档、走何种链路）——那是下游 skill 的职责

## 与 clarify-gate 的分工

- **clarify-gate**（意图识别**前/中**）：需求模糊时 AI 主动反问补齐信息（G1/G2）
- **intent-gate**（意图识别**后**）：需求已结构化为快照，**可选**复述一次供用户发现误识别

## 实现（可运行工具）

> 本工具已由 [`intent-gate.py`](./intent-gate.py) 提供**可运行实现**。落盘规则与 `SKILL.md §四` 保持单一事实源。

### 调用方式

```bash
# 1) 按意图编码快速判定落盘去向与路由（返回 JSON 决策）
python3 hooks/intent-gate.py --intent I13 --json

# 2) 结合快照渲染轻量复述 + 路由决策
python3 hooks/intent-gate.py --snapshot .tribro/snapshots/I13_xxx.md

# 3) clarify-gate 命中时（先澄清）
python3 hooks/intent-gate.py --intent I11 --clarify --json
```

### 输出契约

- **stdout**：轻量复述文案（可选展示给用户）+ 机器可读决策 JSON
- **JSON 字段**：`{intent, intent_name, flow, route_suggestion, reason}`
  - `flow` ∈ `落盘快照 | 不落盘 | 先澄清`
  - `route_suggestion` 给出下游 skill 路由建议（如 I11→编码开发 skill）
- **退出码**：`0` 正常 / `2` 输入错误或意图无法识别

### 落盘规则（与脚本 `decide_flow` 一致）

| L2 意图 | flow | 路由建议 |
|---|---|---|
| I01–I05 | 落盘快照 | 咨询作答 skill |
| I06–I10 | 落盘快照 | 内容处理 skill |
| I11 / I12 | 落盘快照 | 编码开发 skill |
| I13 | 落盘快照 | 规划拆解 skill |
| I14 | 落盘快照 | 操作执行 skill |
| I15 | 落盘快照 | 多媒体生成 skill |
| I16 | 落盘快照 | 头脑风暴 skill |
| I17–I20 | 不落盘 | 表达陪伴 skill（直接自然回应） |
| M01–M04 | 落盘快照 | 元操作处理 skill |
| M05 | 不落盘 | 即时叫停/放行 |
| 任意非表达类 + --clarify | 先澄清 | 先走 clarify-gate 补齐后再识别 |

### Agent 接入点

1. 产出快照 `snapshot.md` 后，**可选**调用本工具获取复述文案与路由建议；
2. 将复述文案展示给用户（可选）；
3. 用户指出误识别 → 更新快照中的结构化结论；
4. 将快照交接给 `route_suggestion` 指向的下游 skill。
