# I15 多媒体生成（Doing）

## 识别特征

- 动词为 **画 / 生成图 / 出个图表 / 做张 / 配图 / 生成语音/视频/PPT**
- 产物是**非纯文本**：图片、流程图、架构图、音频、视频、演示文稿
- 典型语料：「画个系统架构图」「生成一张赛博朋克风壁纸」「做个数据柱状图」

## 与邻近意图边界

- vs **I06 内容生成**：I06 产文本，I15 产多媒体
- vs **I08 翻译转换**：I15 是跨模态生成，非等价转换
- 代码可渲染的图（Mermaid/流程图）优先用文本描述生成，图像类走绘图工具/MCP
