# I14 操作执行（Doing）

## 识别特征

- 动词为 **执行 / 运行 / 帮我操作 / 部署 / 调用 / 跑一下 / 直接做**
- 期望 AI **真正调用工具产生副作用**，不只是给指引
- 常为**长程多步**任务（D3 Agent 型）
- 典型语料：「把这个项目跑起来」「部署到测试环境」「批量重命名这些文件」

## 与邻近意图边界

- vs **I13 规划拆解**：I13 只出计划，I14 实际动手执行
- vs **I11 编码开发**：I11 产出代码交付，I14 侧重运行/操作既有系统
- vs **I01 信息查询（分步指引）**：若用户只要「怎么操作的步骤」→ 归 I01/I03
