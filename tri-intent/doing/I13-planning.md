# I13 规划拆解（Doing）

## 识别特征

- 动词为 **规划 / 拆解 / 制定计划 / 设计方案 / 排期 / 出个路线图 / 分几步**
- 产出是**结构化的行动蓝图**（阶段/步骤/里程碑/依赖）
- 典型语料：「拆解这个项目的开发任务」「制定三个月学习计划」「设计系统架构方案」

## 与邻近意图边界

- vs **I03 建议咨询**：I03 给方向性建议，I13 给成体系的可执行计划
- vs **I11 编码开发**：I13 出「怎么做的方案」，I11 出「实现的代码」
- vs **I14 操作执行**：I13 只规划不落地执行，I14 实际动手操作

## 工作流设计子类路由

> 若任务要点含工作流设计语义（工作流/流水线/审批流/自动化流程/CI-CD/编排/pipeline），`下游路由建议` 覆写为 tri-workflow，L2 保持 I13 不变。详见 `workflow-design.md`。
