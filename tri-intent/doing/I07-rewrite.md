# I07 内容改写（Doing）

## 识别特征

- **必有原文**（用户粘贴或引用），动词为 **润色 / 改写 / 扩写 / 缩写 / 换个说法 / 改正式点**
- 保留核心信息，改变表达形态
- 典型语料：「帮我把这段话改得更专业」「这封邮件润色一下」「扩写成 500 字」

## 与邻近意图边界

- vs **I06 内容生成**：I07 必须有原文，I06 从零起
- vs **I08 翻译转换**：I07 同语言内加工，I08 跨语言/跨格式转换
- vs **I02 概念解释**：I07 改的是表达，不改变含义
