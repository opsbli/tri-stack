# I12 调试修复（Doing）

## 识别特征

- 出现 **报错 / 不生效 / 崩溃 / 结果不对 / 卡住 / 为什么会这样**
- **存在既有代码或系统的故障**，目标是恢复正常
- 典型语料：「这段代码报 undefined」「接口 500 了」「样式没生效」

## 与邻近意图边界

- vs **I11 编码开发**：I12 修坏的，I11 造新的
- vs **I05 推理计算**：I12 面向真实系统故障，I05 是纯逻辑题
- vs **I10 分析处理**：I12 目标是「修好」，I10 止于「分析」
