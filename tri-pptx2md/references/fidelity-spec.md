# 保真度分级规范（tri-pptx2md 唯一事实源）

> 本文件把用户的「高质量无损转化」诉求落为**可验证的分级保真**。置信度阈值、关键数据口径的唯一真源；`scripts/quality_check.py` 是其可执行实现。
> **grep 检索模式**：按阈值 `grep -n "置信度"`；按指标 `grep -n "页覆盖率|文本召回率|丢失率"`；按复核 `grep -n "复核项"`。

---

## 一、诚实声明（契约固定文案，报告必带）

> PPT 是面向演示的排版容器：动画/过渡/母版/精确排版是「表现层」，转 MD 时**必然丢失**；图表/SmartArt 只能以图片资产保留，不能转成正文。PPT→MD 本质是**结构降维而非格式复制**。本 skill 承诺的是「可验证的分级保真」——页覆盖率/文本召回率可计算、置信度可分级、复核项可执行——NEVER 承诺绝对无损。

**理论上不可无损的维度**（结构性限制，任何工具相同）：动画/过渡（表现层，转 MD 即丢弃）、母版与占位符（版式继承，正文只取占位符文本）、精确排版（字号/颜色/位置）、图表/SmartArt（只能提图不能转正文）、页内多文本框阅读顺序（依赖 z-order/坐标推断）。
**可高质量的维度**：每页标题与正文要点（召回 ≥95% 可达）、演讲者备注（引用块保留）、图片资产（提取为 assets/ 并保留页内引用）、页序（`## Slide N` 锚点）。

---

## 二、关键数据口径（用户硬要求：报告 MUST 告知）

| 关键数据 | 口径定义 | 计算实现 |
|---|---|---|
| **页覆盖率** | MD `## Slide N` 块数 / 源 slide 数（上限 100%） | `quality_check.py` `compute_metrics()` |
| **文本召回率（保真率）** | 源提取文本归一化字符 bigram 被 MD 覆盖的比例 | 同上 `recall` |
| **丢失率** | 1 − 文本召回率；附缺页明细（源有而 MD 无的 Slide） | 同上 `loss_rate` / `missing_pages` |
| 结构对比 | 每页文本/图片/备注：PPT 侧计数 vs MD 侧计数 | `count_md_structure()` vs 源提取计数 |
| 置信度等级 | A/B/C，判定见 §三 | `grade_confidence()` |
| 转换元数据 | 后端/档位/页数/耗时/资产数/降级轨迹 | 门A/B/C 过程数据 |
| 异常清单 | 乱码 U+FFFD/空 MD/缺页 | 正则 + 长度启发式 |

**归一化规则**（跨格式公平比较）：先做 **NFKC 折叠**（全角字母/数字与兼容字符归一到半角），再仅保留字母（小写化）+ 数字 + CJK 字符，其余剔除；按字符 bigram 集合求交。

**源侧 bigram 口径（v1.4.4 起 MUST）**：源文本 **逐页**切 bigram 后求并集，NEVER 把所有页拼成一个串再切。跨页边界不是真实邻接，拼接会凭空造出「源侧存在、MD 侧因页序锚点而永远匹配不到」的伪 bigram，导致**完美转换也拿不到 100% 召回**（实测 3 页重复度高的 PPT 仅 92.86%，与 §一「每页标题与正文要点召回 ≥95% 可达」相悖）。**源文本为空（纯图片 PPT）**：文本召回率显式标注「不适用（无文本）」，置信度按页覆盖率与异常判定，NEVER 编造数值。

## 三、置信度分级阈值（唯一真源）

| 置信度 | 判定标准 | 处置 |
|---|---|---|
| **A 直接可用** | 页覆盖 **100%** 且文本召回 ≥ **95%** 且无异常 | 交付，报告标注；固定复核项仍列出 |
| **B 抽查复核** | 页覆盖 **≥90%**（且召回 **≥85%**），或文本召回 **85–95%**（页覆盖未达 90%） | 交付 + 列出复核项与缺页明细 |
| **C 强制人工复核** | 页覆盖 **<90%**，或文本召回 **<85%**，或检出乱码/空输出/缺页/多写块 | 交付 + 醒目警示 + 建议升级档位重转（沿降级链反向：L0→L1） |

**B/C 判定顺序（v1.4.4 裁决 · 消除 B 与 C 的重叠区间）**：原表在「页覆盖 ≥90% **且** 召回 <85%」时 B、C 两行同时命中，实现按 if/elif 顺序判为 B，使 C 行「召回 <85%」在页覆盖达标时恒不可达。**裁决：召回 <85% 优先判 C**（正文缺失过多，页覆盖达标也不放行）。理由文案 MUST 与命中条件一致，NEVER 硬编码「85–95%」区间。

**「结构丢失」的口径澄清**：C 行的「结构丢失」指**缺页 / 空 MD / 乱码 / MD 多写 Slide 块**；**图片资产缺失与演讲者备注缺失只做 A→B 降级**（内容主体仍在，属可抽查复核范围），并在报告「结构对比」与理由中显式列出。

**降级/升级判定**（阈值联动 `detect_backends.py` GRADE_ORDER）：C 级报告 + 用户要求重转 → 建议升档（L0 结果差 → 试 L1）；L1 后端执行失败 → 沿链降档重试。

## 四、固定复核项清单（永不消失，即使 A 级）

report.md MUST 固定列出，用户复核后回填「复核结果回填」段（反哺进化契约）：

1. 演讲者备注丢失（备注在 MD 中未保留或内容不全）
2. SmartArt/图表转图片（SmartArt 只能提图，文字内容可能丢失）
3. 母版占位符（母版/版式上的固定文本可能未进入正文）
4. .ppt 旧格式兼容（OLE 转换后版式/字体可能漂移）
5. 页内多文本框阅读顺序（同页多文本框的 z-order/坐标推断可能错序）

## 质量四维抽评（可选 · P2-1 · 默认关闭）

> 方法论蒸馏自 anydoc 基准四维盲评（completeness / structure / formatting / cleanliness，LLM-judge 双 swap 交叉）——蒸馏报告 docs/distill-anydoc-main-20260908.md P2-1。本节是 SKILL.md 门D「质量四维 LLM 抽评」的唯一真源。

| 维度 | 定义 | 典型扣分点 |
|---|---|---|
| completeness 完整性 | 源信息是否全部进入 MD（文本/表格/列表/脚注/图片引用） | 段落遗漏、表尾截断、脚注丢失 |
| structure 结构性 | 标题层级/列表嵌套/表格网格是否与源一致 | 层级压平、列错位、嵌套丢失 |
| formatting 格式保真 | 加粗/斜体/代码/链接/公式 LaTeX 是否保真 | 样式丢失、锚点断裂、公式乱码 |
| cleanliness 洁净度 | 噪声率：残留标签/冗余空行/转换伪影 | HTML 残留、重复页眉、乱码 U+FFFD |

执行规则：

1. **默认关闭**：确定性指标（保真率/丢失率/结构对比/置信度）已交付时，NEVER 自动附加本抽评。
2. **启用 = 付费确认场景（总则②）**：MUST 用户显式二次确认后才执行；执行前告知额外成本。
3. **盲评双 swap**：四维各 1–5 分；两名 judge 独立评（顺序互换 A/B），分差 ≥2 的维度 MUST 标注「分歧」并列入人工复核项。
4. **抽样**：文档 ≤10 页全量；>10 页按标题分层抽样（≥3 层、每层 ≥1 块、总量 ≤10 块）。
5. **结果落盘**：report.md 追加「质量四维抽评」段（四维得分/分歧项/抽样清单/基准来源标注）；基准引用一律标注出处，NEVER 裸引数字。

## 五、修订规则

- 阈值调整只改本文件 §三 + `quality_check.py` 顶部常量（两处 MUST 同步，CHANGELOG 记录）。
- 触发修订的条件（进化契约）：同类 PPT 连续 ≥3 次 C 级；后端能力排名显著变化；新复核项被用户回填确认。
