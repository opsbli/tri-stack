## 2. 原子任务清单

> **原子化原则**：每个任务可独立执行、独立验收、独立回滚；粒度以「单一职责、单一产出」为准。

> **复选框状态切换规则（核心机制 · 全程适用）**：
> - 每个原子任务的完成状态由「完成状态」字段的 Markdown 复选框唯一表示：`` `- [ ]` `` = 未完成，`` `- [x]` `` = 已完成
> - **执行完成** → MUST 将复选框由 `` `- [ ]` `` 切换为 `` `- [x]` ``
> - **回炉重做**（测试不过）→ MUST 将复选框由 `` `- [x]` `` 重置为 `` `- [ ]` ``
> - 「状态明细」字段为辅助标注，用于记录复选框无法表达的中间态：待执行 / 执行中 / 已阻塞 / 已跳过

## 3. 测试清单

> **三层测试覆盖**：单元测试（UT）验证单个任务产出，集成测试（IT）验证模块间协作，验收测试（AT）验证需求达成。
> **复选框状态切换**：与 §2 任务一致，每条测试的「完成状态」字段使用 `` `- [ ]` `` / `` `- [x]` `` 复选框表示执行状态。「状态明细」记录结果：未执行 / 通过 / 失败 / 阻塞 / 跳过。
