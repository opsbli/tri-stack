# 19 类不译规则集（references）

> 本文件是 `tri-translate` 的不译规则单一事实源。SKILL.md 仅保留摘要与指针，正则模式全集在此。
> grep 检索：按类别名或占位符类型检索，如 `grep -n "URL" references/no-translate-rules.md`。

## 规则表

| # | 类别 | 识别模式（正则简写） | 占位符 |
|---|------|---------------------|--------|
| 1 | 绝对路径 | `/[a-zA-Z]?:?\\\\?[^/\s]+[/\\][^/\s]+` | `__PATH_<N>__` |
| 2 | 相对路径 | `(\.\./|\./)[^\s]+` | `__PATH_<N>__` |
| 3 | 围栏代码块 | ` ```[\s\S]*?``` ` | `__CODEBLOCK_<N>__` |
| 4 | 行内代码 | ` `[^`]+` ` | `__CODE_<N>__` |
| 5 | 命令行 | `^[$>]\s+\w+` 或行首 `$ ` | `__CMD_<N>__` |
| 6 | API 端点 | `(GET\|POST\|PUT\|DELETE\|PATCH)\s+/[^\s]+` | `__API_<N>__` |
| 7 | URL | `https?://[^\s]+` | `__URL_<N>__` |
| 8 | 域名 | `[a-zA-Z0-9.-]+\.[a-zA-Z]{2,}`（结合上下文） | `__DOMAIN_<N>__` |
| 9 | 邮箱 | `[a-zA-Z0-9._%+-]+@[a-zA-Z0-9.-]+` | `__EMAIL_<N>__` |
| 10 | 配置键 | YAML `^\w+:` 或 JSON `"\w+":` 键名 | 保留键名 |
| 11 | 环境变量 | `\$[A-Z_][A-Z0-9_]*` 或 `\$\{[A-Z_]+\}` | `__ENV_<N>__` |
| 12 | 版本号 | `v?\d+\.\d+(\.\d+)?` | 保留 |
| 13 | SHA/哈希 | `[0-9a-f]{7,40}` | 保留 |
| 14 | 品牌名/产品名 | 术语表 Priority A | 保留 |
| 15 | 商标 | `™\|®` | 保留 |
| 16 | 首字母缩写 | `[A-Z]{2,}` 且非全大写单词 | 保留（首现可附中文） |
| 17 | 技术标识符 | 驼峰或下划线变量/函数/类名 | 保留 |
| 18 | 数字与单位 | `\d+(\.\d+)?\s?[A-Za-z%]+` | 保留 |
| 19 | 日期时间 | ISO 8601 或文档约定格式 | 保留 |

## 占位符还原约定

- 翻译过程 NEVER 翻译占位符（`__<TYPE>_<N>__`）。
- 译后 MUST 还原所有占位符；残留占位符 ≠ 0 则 NEVER 交付。
- 还原后生成 `preserved.md` 列出所有保留原文要素及类型。

## 维护

- 新增规则：在本表追加一行（# / 类别 / 识别模式 / 占位符），并在 `templates/never-translate.json` 同步追加 `{id,name,pattern,placeholder,description}`。
- 正则模式以本文件为准；`never-translate.json` 是运行时载体，二者保持一致。
