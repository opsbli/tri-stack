# shot-card-system — 镜头配方卡体系

> 镜头配方卡是代码渲染路线的运动词汇库：每张卡记录一种动效镜头的语义、参数表与已知坑。
> 本文件定义卡片 schema、分类学、用卡法则与全片能量弧模板；新增卡片按本 schema 扩充。
> 装配层级：常驻层（代码渲染路线阶段 2–3、逐镜头实现时使用）。
> grep 定位模式：`配方卡`、`能量`、`段位`、`frontmatter`、`命门`。

## 1. 卡片 frontmatter schema

```yaml
---
name: <卡名，小写连字符>
一句话: <该镜头在做什么，含机位/主体/动效/收尾的完整描述>
适用: <什么内容/页面状态/叙事位置用它；建立什么印象>
时长: <建议时长与帧段，含可选拆分>
能量: <低/中低/中/中高/高 + 在全片能量曲线中的位置约束>
---
```

正文固定六段：**意图**（为什么这样设计、观众感受目标）→ **动效核心**（分层动作编排，
含预备拍/跟随/拖拽层级等动画法则引用）→ **参数表**（| 参数 | 典型值 | 调节手感 | 三列，
参数给到帧号/缓动函数/像素量级）→ **声音**（钉帧建议与音色）→ **已知坑**（实测返工教训，
含「命门」参数）→ **参考实现**（指向 demo 源码路径）。

## 2. 十类分类学

| 类别 | 职责 | 代表手法（描述性） |
|---|---|---|
| opening（开场） | 全片第一印象 | 品牌字标压印开场、单主角聚光推近、裂纹汇聚、字符逐笔成形 |
| camera（运镜） | 真实页面/3D 场景的相机语言 | 急推冲击、2.5D 深度分层移动、掠面巡览、高空俯冲降落、侧斜环绕 |
| ui-entrance（元素入场） | UI 元素进入画面 | 卡片发牌硬加速、行级嵌入、堆叠按压、骨架揭示、SVG 描迹、径向波 |
| typography（文字动效） | 标题/字卡/字幕 | 打字机揭示、乱码轮播、翻牌字、逐词接力、模糊滑入、轮廓填充 |
| transition（转场） | 镜头衔接 | 遮挡隐藏切、卡片翻揭、马赛克重构、色块步进擦除、白闪简化、纸张飞机携带 |
| rhythm（节奏） | 群体运动与节拍 | 节拍切割、蒙太奇节奏、速度坡道冻结、四分屏并行、残影多重曝光 |
| effects（特效） | 光效/HUD/氛围 | 扫光标注、FUI 抬头显示、riso 印刷撞击、扫描线聚焦、聚光灯扫掠 |
| data（数据可视化） | 数字/图表/信息图 | 里程计数字滚动、仪表读数、图表实时生长、粒子庆祝命中、前后对比滑块 |
| interaction（交互演示） | 模拟真实操作 | 输入触发、主题切换、命令面板召唤、协作光标、语音波形、分段选择 |
| outro（收尾） | 品牌落版 | 合影式围拢字标、logo 缩小字标锁定、UI 剥离收尾、颗粒溶解 |

## 3. 用卡三读法则（硬规则，不可跳）

1. **先读卡全文**：卡给的是语义和参数表——意图、动效核心、已知坑。
2. **再读参考实现源码全文**（若有）：demo 代码是调校过的**参数真相**（缓动、时值配比、
   已知坑规避写法都在里面）。允许按目标产品做适配性改动，但卡上「已知坑/命门」标注的
   参数**不得降档——质量标准只升不降**。凭卡名和理解新写 = 放弃全部调校积累，实测质感差一档。
   **库内暂无参考实现时**（自建卡或外部卡未带 demo）：以卡面参数表为参数真相逐项落到
   代码，静帧验收帧号加倍（4 个：入场中/动作峰值/落定/收尾），实现完成后把实测教训回填
   卡片「已知坑」段；命门参数「只升不降」原则照常适用。
3. **后 copy 组件进工程**：可复用组件（2.5D 页面相机/数字化滚动/闪切/字幕等）copy 后自由
   修改，不跨工程 import；若使用外部卡库的样片，同时保存该 style 的参考样片路径供实现
   对照与终检。

标为「仅供参考，需要自定义实现」的样式不默认推荐，用户明确点名后才实现并标注风险。

## 4. 全片能量弧段位模板（分镜阶段先填骨架再挑卡）

把节奏规则合成一条可直接填空的全片曲线。默认项不是令：逐项目可有意识偏离，偏离写进项目
设计 spec。30–60s 多功能产品宣传片的收敛骨架：

| 段位 | 时长占比 | 能量 | 职责 | 候选手法 |
|---|---|---|---|---|
| ① 品牌开场 | 8–12%（开场+立传合计可达 20%） | 低 | 字标压印 + hold ≥1s（R1），交棒产品页面 | 字标压印类开场 |
| ② 单主角立传 | 12–15% | 中（质感最高、节奏最慢） | 一个主角、一条完整动作弧 ≥3s（Q5/R3），立出产品原子单位 | 聚光推近/悬浮归位类 |
| ③ 功能爬升段 | 55–65% | 中高⇄低交替 | 每镜绑一个独特功能、一种手法只当一次主角（P4）；镜间按需插呼吸字卡 | 发牌/输入筛选/列表堆叠/文档打字机等 |
| ④ 发布会收场 | 13–16% | 峰值（全片最高） | 已展示功能各出代表元素合影围住字标（Q8），sign-off hold ≥1s（R1） | 合影式收场 |

呼吸字卡规则：每 1–2 个功能镜头后插一张，单张 50–55f（≈1.8s），全片 2–4 张；重要功能
出场前用作引导字卡（C2）。

填空流程：① 列产品功能清单（P4），数出功能镜头数 N；② 按段位表分配总帧数：先扣 ①②④
与字卡预算，剩余给 ③ 均分；③ 每个功能镜头从对应类别挑卡（首选+备选各一）；④ 有指定 BGM
时镜头边界锚拍号（beat-sync-sound.md）。

## 5. 自建卡规范（库内无合适卡时）

1. 按 §1 schema 新建卡片，正文六段齐全，参数表给到帧号/缓动/像素量级。
2. 在设计 spec 说明「为何现有卡不适用 + 新卡验证风险」。
3. 新卡的已知坑段**必须**在第一次实现后回填实测教训；命门参数同样适用「只升不降」。
4. 分类归位到 §2 十类之一；能量标注须与段位表自洽。
