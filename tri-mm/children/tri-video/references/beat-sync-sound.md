# beat-sync-sound — BGM 卡点方法论与声音设计

> 代码渲染路线：强节奏 BGM 片的所有转场和关键动效必须落在拍上；声音设计排在画面锁定后。
> 装配层级：常驻层（用户已选 BGM → §1–4 必读；所有带音频的片子 → §5 必读）。
> grep 定位模式：`卡点`、`BPM`、`beatF`、`钉帧`、`SFX`、`音画`。

## 1. 何时启用：音乐先行铁律

阶段 0 检查用户是否已指定音乐：已选好 → 先做节奏分析，网格验收通过前**不设计分镜**；
未选 → BGM 选型放到阶段 6，时间线按内容节奏排，不强行卡点。时长对不上时改时间参数，
不删改用户文案。分析全程用浮点秒记录时刻，**换算成帧只发生在进渲染引擎的最后一步**
（提前取整会让误差在管线里滚雪球）。

## 2. 节拍网格测定（不要相信 beat_track 的 tempo 标量）

用 librosa 做节拍检测，**关键一步：对 beat 时刻序列做最小二乘等距网格拟合**求真实 BPM
与相位——beat_track 返回的 tempo 标量可能偏差 2%+（实测 129.2 vs 真值 131.97），但它
输出的 beat 时刻序列本身是好的：拟合 `t_i = t0 + i*T` 得到真值。验收标准：**残差
≤ ±15ms（半帧内）**说明曲子是机器鼓点、网格可信；残差大说明有变速段，需分段拟合。
确定性算法已下沉为 `scripts/beat_grid_fit.py`（网格拟合 + 半倍/双倍歧义裁决 +
JSON 网格输出）。

- **半倍/双倍歧义必查**：检测常在 2x/0.5x 间跳（70 BPM 报成 140）。判据不是听感，是鼓点
  数据——正确网格下 kick 应主要落在整数拍；0.5x/1x/2x 三个候选按鼓点覆盖率指标各算一遍
  选最高。
- **复杂曲先分离鼓 stem**：人声/贝斯厚的编曲会把鼓的攻击埋掉；轻量方案 HPSS 取打击成分，
  重方案 Demucs 分离整条鼓轨。

## 3. 鼓点分类与能量结构

kick/snare/hihat 三分类定位（onset 按频段能量分流）；产出三件表：
- **满能量起点表**：全曲能量结构（intro/verse/drop/breakdown/outro 的秒区间）；
- **breakdown 拍号表**：低能量段天然是品牌呼吸位（R1 的 hold 段落首选）；
- **最强 hit 清单**：按瞬态强度排序——全片 2–3 个大 slam（R4）从这里分配。

网格按**瞬态覆盖率**验收通过后才进入分镜。

## 4. 用拍号编排时间线 + 渲后回测

- 时间线帧号一律用拍号表达式 `beatF(n)` 写（n 可为分数拍）；稀疏重音**钉真实瞬态时刻**
  而非网格插值点。
- 镜头边界全锚拍号；breakdown 段给品牌呼吸位；最强 hit 分给 2–3 个大 slam，其余拍点动效
  只动元素层（R4：卡点管时机不管幅度）。
- **渲后回测（必做）**：从成片抽音轨，对全部切点计算与拍网格的误差，**全部 ≤3f（感知阈值
  约 3f）才算过**；实测参考：70s/18 镜/131.97 BPM 宣传片按此法全切点误差 ≤2.2f。

## 5. 声音设计（画面时间线锁定后才开始）

**顺序：画面结构基本锁定 → 先铺 BGM 定能量骨架 → 逐拍钉 SFX。** 画面每动一次，钉帧表
全体重对（S3）——有一次把换 BGM 和画面重做混在同一轮，画面继续改，全表报废重钉。

### 5.1 BGM

- 音量压低 ~0.34 给 SFX 留 headroom，首尾淡入淡出（如 1s 淡入、1.7s 淡出）。
- 选型判据：鼓点强、节奏感强的电子底（tech-house 类）；气质基准是「典型的产品宣传片」
  而非「好听」；**候选曲必须垫进成片试听后再定**——单听曲子无法判断气质（实战：34 分钟
  三易其稿，前两稿都因没在成片语境里试听被否）。能量曲线要对得上分镜能量曲线（低开→中段
  推进→峰值收场）；旋律太抢的曲子会和拟音打架。
- BGM 用布尔 inputProp（默认 true）单独包住与 SFX 解耦——**配 BGM 的片子终渲固定交付
  两版**（带 BGM + 无 BGM 保留 SFX），从同一时间线渲出；Windows shell 会剥掉内联 JSON
  的双引号，props 用文件传最稳。
- 音频素材只用授权明确、允许免费商用的来源，入工程时记录来源与授权条款。

### 5.2 SFX 词汇表与钉帧表

- 词汇按片种选（S1）：whoosh(运镜)/impact(落地)/riser(铺垫)/sparkle(光效)/transition
  (转场)；禁游戏音包音色不禁动作；素材目录按场景分 16 类（transition impact riser camera
  ui text paper film light data scifi mech glass fluid crowd counter），**先定类别再挑
  音色**——注意 sparkle 词汇对应目录名常为 `light/`。
- **声明式钉帧表集中管理**（S2）：单文件 `{ from, src, volume }[]` 数组，逐条注释对应的
  画面动作，渲染时每条包一个从 from 起的序列；**from 一律写相对表达式**——
  `SHOTS.x.from + offset`、卡点片写 `beatF(n)`，绝不写裸数字帧号；时间线平移时钉帧表自动
  跟随，免除全表重钉。
- **长样本（>5s）必须显式给 durationInFrames**——靠序列截断而非剪音频文件；漏给会拖到
  动作结束后还在响（S4）。带长尾混响的 impact 例外，让尾音自然衰减。
- **音量按素材实测峰值给**（S4）：volume 是乘法系数不是目标音量；峰值 <-12dB 的轻音素材
  给到 1.0 仍会被 BGM 盖住——首选换同类别录得好的素材或预归一化，必要时 >1 增益并以
  渲染产物验峰防削波（预览可能钳到 1.0）。

### 5.3 动效句式与收尾

- 连发防机枪三招（S2）：双样本交替、音量阶梯递减、间隔加速贴动画曲线；密到糊成一片时让
  声音淡出成 swoosh。
- 拟音优先（S4）：有辨识度的画面动作配它自己的拟音（打字配键盘、逐条落入配逐个 pop），
  泛用 swoosh 盖不住。
- **结尾固定句式**：riser（组装段起）→ impact（字标落地，全片音量峰值）→ sparkle（余韵）。
- 强鼓点 BGM 片 SFX 克制：鼓点本身就是节拍音，SFX 只钉画面独有动作，大 slam 只给 2–3 处
  峰值（R4）。

### 5.4 音画对齐终检（S5）

逐条 SFX 对帧回放确认无错位；时间线在声音阶段后动过 → 先全表重对再验。输出音轨偏移与
音源峰值滞后两项按 aesthetic-rules.md S5 实测补偿；卡点片按 §4 回测全部切点 ≤3f 才算过。
