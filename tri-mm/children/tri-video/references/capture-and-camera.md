# capture-and-camera — 素材采集三件套与 2.5D 页面相机

> 代码渲染路线阶段 4（最终素材采集）与逐镜头实现（2.5D 运镜）的方法论。
> 装配层级：常驻层（代码渲染路线）。
> grep 定位模式：`三件套`、`layout.json`、`PageCam`、`栅格化`、`cutout`。

## 1. 素材采集三件套（分镜放行后才做）

起产品本地 dev server（桌面端产品用窗口截图工具，同样出三件套），现场编写一个**一次性可
配置采集脚本**（Playwright/Puppeteer 均可；配置项：BASE_URL/路由/语义选择器；采集完归档
进项目便于增量重采），一次产出：

1. **全页 2x 截图**：viewport 1920×1080、`deviceScaleFactor: 2`；截图前
   `document.fonts.ready` + 600ms settle，实时同步页额外再等 1.5–2s。
2. **per-element cutout**：按语义选择器逐元素截图；悬浮件用透明底；需要「卡片飞入空板」
   的镜头额外截空 backplate。
3. **layout.json**：记录每个元素在整页坐标系下的 `{x,y,w,h}` bbox 与每页 `pageH`——供
   飞行目标位、遮罩位置和入场区域直接使用；页面空间 overlay 与它共坐标系。

支持按页/按元素增量重采。**数据安全口径**：公开演示数据只有确认公开属性后可保留；客户、
个人、内部、密钥、实时或其他敏感数据必须用虚构或脱敏内容，且在采集前冻结。复刻既有页面
必须用真实截图（Q1）；手搓 UI 限非复刻场景且质量/表达双硬门槛达标。

## 2. 2.5D 页面相机（一切「真实页面」镜头的地基）

整页纹理 + 关键帧相机 + 页面空间 overlay 三层模型：

- **CamKey 关键帧模型**：`{ frame, cx, cy, zoom, rotX?, rotY?, rotZ?, persp? }`——
  `(cx, cy)` 是页面空间 CSS 点（居中到 1920×1080 视口），`zoom` 为缩放（1 = 1 CSS px →
  1 输出 px），rotX/rotY/rotZ 为倾斜/偏航/滚转（度），persp 为透视强度（px，默认约 1400，
  越小越强）。
- **插值**：相邻关键帧之间按缓动函数插值并 clamp（不外推）；整页纹理按 CSS 尺寸渲染
  （2x 纹理源以 width 约束到 CSS 尺寸）。
- **3D 缺省退化**：所有关键帧均无 3D 字段时，标记退化为纯 pan/zoom 且渲染像素一致——
  同一组件同时覆盖平面运镜与 2.5D 运镜。
- **可选 DoF**：屏幕空间梯度模糊带近似焦点平面（倾斜页面的远端模糊）——只做氛围，
  永远不是清晰度解法（Q2）。
- **绝对帧还原**：组件被 `<Sequence>` 包裹时帧号被重定基；给相机组件传显式 `frame` prop
  还原绝对帧，否则按绝对帧编排的关键帧会错帧（与运动模糊包裹组合时必现横向错模糊穿帮）。

## 3. 高清栅格化技法（Q2 展开）

- **根因**：Chromium 对 3D 合成层按布局宽栅格化再 GPU 放大——内容先降采样后放大必糊，
  与相机/景深参数无关。
- **解法**：放大量不走 `transform: scale(zoom)` 而走 CSS `zoom` 属性（布局级缩放），让
  渲染器按放大后的设备尺寸栅格化，从高清源向下采样。坐标须按 `Tx = 960/zoom − cx` 换算
  保持与平面模式取景一致，漏换算会跑焦点。
- **配套**：全页 2x（deviceScaleFactor: 2）+ hero 元素单独 4x 元素级截图 + 推进期 6f
  交叉淡入盖住低倍页面纹理（淡入太长会看到两层错位）。
- **排查顺序**：文字糊 → 先查纹理源分辨率链路（截图倍率→栅格化路径→缩放方式），最后才
  考虑相机。验证用逐帧截图裁剪放大看字边缘，肉眼看缩略图发现不了。

## 4. 与镜头卡的配合

- 采集脚本输出即 2.5D 相机的输入：layout.json 的 bbox 用于元素级飞行/遮罩/入场，全页图
  用于相机运镜纹理。
- 信息密集镜头（列表/堆叠）保持正视（Q6）；物件特写走 Q7 四件套（侧斜+高度+orbit+
  反差深色材质）。
- 相机快速运镜段（≥30px/f）可包运动模糊（shutterAngle≈180、samples 按渲染预算调），但
  **只包快速段**——整镜全包会把慢速段的细纹理采样抹软；快摇拖影是电影摄像机的物理本能，
  30fps 下每帧跳 50–70px 会频闪。
