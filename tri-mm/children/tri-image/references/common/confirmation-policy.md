# 确认门与开关速查（公共层）

> 默认值：**生成前确认**。任何 inputs（显式调用、文件路径、命中关键词、扩展偏好、自动选择结论）都只是**推荐输入**，NEVER 授权跳过确认。

## 开关别名表（统一后）

| 别名 | 等价 | 含义 |
|---|---|---|
| `--quick` | `--yes`、`--no-confirm`、`直接生成`、`不用确认`、`跳过确认`、`按默认出图` | 跳过确认门，用推荐值 |
| `--aspect <ratio>` | — | 跳过比例提问 |
| `--batch-size N` | `并行 N 张一起生成` | 覆盖批量默认 4 |
| `--ref <files...>` | — | 指定参考图 |
| `--regenerate N` | — | 仅重出第 N 张（保留其余） |
| `--images-only` | — | 用已有提示词文件直接出图，跳过分析与 outline |

> 扩展偏好 `quick_mode: true` 是**长期显式退出**，等价于每次都带 `--quick`；仅在用户明确希望免确认时设置。

## 各场景的确认项

| 场景 | 必问 | 仅在前述条件下问 |
|---|---|---|
| 封面图 | 6 维（Type/Palette/Rendering/Font/Text/Mood）+ Aspect | 语言（源语言 ≠ 用户语言）、后端（多选时） |
| 信息图 | 版式×风格组合（给 3–5 个带理由）、Aspect | 语言、后端 |
| 文章配图 | 数量/密度、风格、调色板 | 语言、后端 |
| 社媒卡片 | 拆分策略、风格、版式、卡片数 | 语言、后端 |
| 幻灯片 | 风格、页数、受众 | 语言、后端 |
| 漫画 | 绘画风格、基调、版式、页数 | 语言、后端 |
| 结构图 | 图类型（无法判定时） | 不询问后端（Track-V 无需后端） |

## 跳过确认时的义务

若用户显式跳过确认（或设了长期退出），MUST 在**下一次面向用户的输出里**先声明本次采用的「场景 / 比例 / 语言 / 风格 / 后端」，再开跑。

## Track-V 例外

结构图走确定性管线，无 API 额度消耗，**确认门退化为「仅在图类型不明确时才问」**：用户请求已点明图类型时直接产出；类型不明时才按 `user-input-rules.md` 提问。
