# 保真度分级规范（tri-xlsx2md 唯一事实源）

> 本文件把用户的「高质量无损转化」诉求落为**可验证的分级保真**。置信度阈值、关键数据口径的唯一真源；`scripts/quality_check.py` 是其可执行实现。
> **grep 检索模式**：按阈值 `grep -n "置信度"`；按指标 `grep -n "单元格覆盖率|工作表数对比|行数对比"`；按复核 `grep -n "复核项"`。

---

## 一、诚实声明（契约固定文案，报告必带）

> Excel 是面向计算的二维网格格式：内部含公式逻辑、单元格格式、图表、数据透视等语义，而 Markdown 表格只有「表头 + 分隔行 + 数据行」三层结构。Excel→MD 本质是**结构降维而非格式复制**——公式逻辑/格式/图表/数据透视**必然丢失**，公式默认取缓存值（公式语义丢失）。本 skill 承诺的是「可验证的分级保真」——单元格覆盖率可计算、置信度可分级、复核项可执行——NEVER 承诺绝对无损。

**理论上不可无损的维度**（结构性限制，任何工具相同）：公式逻辑（只能取缓存值）、单元格格式（颜色/字体/边框）、图表/数据透视（只能丢弃或另存）、合并单元格语义（只能展开为左上角值）。
**可高质量的维度**：单元格数据（覆盖率 ≥95% 可达）、工作表结构（每表一个 `## Sheet` 块）、行/列布局（MD 表格行列对齐）。

---

## 二、关键数据口径（用户硬要求：报告 MUST 告知）

| 关键数据 | 口径定义 | 计算实现 |
|---|---|---|
| **单元格覆盖率** | 源非空单元格数被 MD 表格单元格数覆盖的比例 = min(MD 单元格数, 源非空单元格数) / 源非空单元格数 | `quality_check.py` `compute_metrics()` |
| **工作表数对比** | 源工作表数 vs MD `## Sheet` 块数（吻合/不吻合） | 同上 `sheet_match` |
| 行数对比 | 源数据行数 vs MD 数据行数 | 同上 |
| 置信度等级 | A/B/C，判定见 §三 | `grade_confidence()` |
| 转换元数据 | 后端/档位/文件类型/源提取方式/耗时/降级轨迹 | 门A/B/C 过程数据 |
| 异常清单 | 乱码 U+FFFD/空 MD/工作表缺失/截断（<85%） | 正则 + 启发式 |

**源提取规则**：优先 openpyxl（.xlsx）/ xlrd（.xls）；不可用时降级 zipfile 解 `xl/worksheets/*.xml` + `sharedStrings` 提取。**空表（源无非空单元格）**：覆盖率按 1.0 计，MD 为空属正常，NEVER 编造数值。

## 三、置信度分级阈值（唯一真源）

| 置信度 | 判定标准 | 处置 |
|---|---|---|
| **A 直接可用** | 单元格覆盖 ≥ **95%** 且工作表数吻合且无异常 | 交付，报告标注；固定复核项仍列出 |
| **B 抽查复核** | 单元格覆盖 **85–95%**，或部分工作表缺失 | 交付 + 列出复核项与缺失工作表 |
| **C 强制人工复核** | 单元格覆盖 < **85%**，或检出乱码/截断/工作表缺失，或覆盖率无法计算 | 交付 + 醒目警示 + 建议升级档位重转（沿降级链反向：L0→L1） |

**降级/升级判定**（阈值联动 `detect_backends.py` GRADE_ORDER）：C 级报告 + 用户要求重转 → 建议升档（L0 结果差 → 试 L1）；L1 后端执行失败 → 沿链降档重试。

---

## 四、固定复核项清单（永不消失，即使 A 级）

report.md MUST 固定列出，用户复核后回填「复核结果回填」段（反哺进化契约）：

1. 合并单元格（展开为左上角值 + 其余空，复核展开是否正确）
2. 公式 vs 值（默认取缓存值，公式语义丢失；复核缓存值是否为最终值）
3. 多行表头（表头跨多行时 MD 表头仅取首行，复核表头完整性）
4. .xls 旧格式兼容（BIFF 解析差异，复核单元格内容）
5. 超大数据集截断（>100k 行时 MD 可能截断，复核行数）
6. 日期/数字格式（Excel 日期序列号 vs 显示格式，复核格式语义）

## 质量四维抽评（可选 · P2-1 · 默认关闭）

> 方法论蒸馏自 anydoc 基准四维盲评（completeness / structure / formatting / cleanliness，LLM-judge 双 swap 交叉）——蒸馏报告 docs/distill-anydoc-main-20260908.md P2-1。本节是 SKILL.md 门D「质量四维 LLM 抽评」的唯一真源。

| 维度 | 定义 | 典型扣分点 |
|---|---|---|
| completeness 完整性 | 源信息是否全部进入 MD（文本/表格/列表/脚注/图片引用） | 段落遗漏、表尾截断、脚注丢失 |
| structure 结构性 | 标题层级/列表嵌套/表格网格是否与源一致 | 层级压平、列错位、嵌套丢失 |
| formatting 格式保真 | 加粗/斜体/代码/链接/公式 LaTeX 是否保真 | 样式丢失、锚点断裂、公式乱码 |
| cleanliness 洁净度 | 噪声率：残留标签/冗余空行/转换伪影 | HTML 残留、重复页眉、乱码 U+FFFD |

执行规则：

1. **默认关闭**：确定性指标（保真率/丢失率/结构对比/置信度）已交付时，NEVER 自动附加本抽评。
2. **启用 = 付费确认场景（总则②）**：MUST 用户显式二次确认后才执行；执行前告知额外成本。
3. **盲评双 swap**：四维各 1–5 分；两名 judge 独立评（顺序互换 A/B），分差 ≥2 的维度 MUST 标注「分歧」并列入人工复核项。
4. **抽样**：文档 ≤10 页全量；>10 页按标题分层抽样（≥3 层、每层 ≥1 块、总量 ≤10 块）。
5. **结果落盘**：report.md 追加「质量四维抽评」段（四维得分/分歧项/抽样清单/基准来源标注）；基准引用一律标注出处，NEVER 裸引数字。

## 五、修订规则

- 阈值调整只改本文件 §三 + `quality_check.py` 顶部常量（两处 MUST 同步，CHANGELOG 记录）。
- 触发修订的条件（进化契约）：同类 Excel 连续 ≥3 次 C 级；新复核项被用户回填确认；WPS 兼容性新问题。
