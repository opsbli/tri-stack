# tri-bs

头脑风暴下游执行 skill。读取 tri-intent 快照 §三 结构化结论，处理 I16（创意发散/头脑风暴）意图，通过横向穷举、纵向深挖、跨域联想三种发散方法的组合使用，产出多个异质化候选点子/方案/可能性。遵循「只发散不收敛」原则——给多个候选供用户评估，收敛决策归 tri-ask 的 I04。

## 特性

- **3 种发散方法组合使用**：横向穷举铺面 + 纵向深挖/跨域联想补异质化，至少组合两种方法确保候选非同质化
- **只发散不收敛原则**：产出多个并列候选，不替用户收敛到单一方案（收敛归 tri-ask 的 I04 决策辅助）
- **候选四要素**：每个候选含标题 + 一句话说明 + 适用场景 + 优劣简评，可独立评估
- **任务要点覆盖核对**：逐项核对快照任务要点清单，确认全覆盖或显式标注未覆盖项
- **轻量无审批门**：单轮即交付，候选集合即时对话回应，不落盘
- **可独立安装**：支持两态上游依赖检测（快照模式/引导安装），不支持降级模式

## 安装

将 `tri-bs/` 目录放入你的 skills 目录即可：

```bash
cp -r tri-bs/ /path/to/your/skills/
```

> 本 skill 依赖 tri-intent 进行意图识别与输入校验。独立使用时会检测上游依赖，未检测到 tri-intent 将引导安装。

## 使用

### 1. 核心流程

当 tri-intent 快照下游路由建议指向本 skill 时激活，按以下步骤推进：

1. **读取快照**：读取 `.tribro/snapshots/<命名>.md` §三，校验 `intent.L2_核心意图` = I16
2. **多角度发散**：至少组合使用两种发散方法（横向穷举/纵向深挖/跨域联想），确保候选间有差异性
3. **候选评估与组织**：每个候选拟定四要素（标题+说明+适用场景+优劣简评），按 D4 格式约束组织
4. **任务要点覆盖核对**：逐项核对快照任务要点清单，确认全覆盖或标注未覆盖项
5. **交付**：输出候选集合，末尾声明「只发散不收敛」，收敛路径指引 tri-ask 的 I04

### 2. 发散方法

| 发散方法 | 操作 | 产出特征 |
|---|---|---|
| 横向穷举 | 在主题同一层面列举尽可能多的并列方向 | 覆盖面广，候选间互斥 |
| 纵向深挖 | 选 1-2 个有潜力的方向逐层向下展开变体 | 有深度，候选间呈递进关系 |
| 跨域联想 | 从其它领域借用模式/隐喻/机制映射到当前主题 | 有新颖性，候选间异质化 |

### 3. 独立安装依赖检测

| 模式 | 触发条件 | 行为 |
|---|---|---|
| A · 快照模式 | `.tribro/snapshots/` 有快照 或 skills 目录有 `tri-intent/` | 读取快照，按工作流推进 |
| B · 引导安装 | 以上均不满足 | 提示依赖并引导安装 tri-intent |

## 设计原则

- **只发散不收敛**：本 skill 只产出多个并列候选，收敛到单一方案的决策归 tri-ask 的 I04 决策辅助
- **多角度组合确保异质化**：至少组合两种发散方法，避免单一维度产生同质化候选
- **候选可独立评估**：每个候选含完整四要素，用户可逐个独立评估，不依赖其它候选
