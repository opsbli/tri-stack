# 去 AI 化引擎（完整参考）

> 📌 本文件为 `SKILL.md` §去AI化写作引擎 中「禁用词表 / 视角库 / 结构模式 / 门禁清单」四块的展开参考，两者冲突时以本文件为准。
> 📌 所有具体数据（人设 / 产品 / 领域池 / 禁用词覆盖）仍由 profile 的 `{{占位符}}` 注入，本文件不写死任何领域或人设。

## 一、禁用词表（出现即不合格，必须重写）

profile 提供 `{{DISABLED_WORDS}}` 时以其为准，为空则回退下表默认。

| 分类 | 禁用词 |
|---|---|
| 八股连接词 | 首先、其次、最后、此外、综上所述、总而言之、值得注意的是 |
| 营销形容词 | 颠覆性、重塑格局、双刃剑、至关重要、不可或缺、深入挖掘、旨在 |
| 模板句式 | 随着……的发展、在当今……时代、本文详细介绍了、完整介绍、手把手教你 |
| 标题烂大街词 | 完全指南、详细教程、手把手教你 |

> 标题另有约束：优先疑问句 / 反常识 / 数字量化 / 对比 / 吐槽式。

## 二、写作风格：放弃「工整」，拥抱「自然流动」

- **不写排比句**，不写「总分总」八股；句子长短不一，允许口语短句或插入语。
- **主动语态 + 口语感**：写「我死活调不通」而非「该问题难以调试」；可用「说白了」「你猜怎么着」「这坑我躺了三天」。
- **允许元素**（随机选 1–2 种）：自嘲 / 吐槽、反问句、临时跑题感慨、技术圈行话（造轮子 / 填坑 / 一把梭 / 胶水代码 / 银弹）。

## 三、个性化视角库（每篇必须有「人味儿」）

从文章类型表中随机选或组合，**不连续两篇相同**。

| 视角维度 | 可选值 |
|---|---|
| 语气/人称 | 第一人称「我」 / 「我们」 / 第二人称「你」 / 混合 |
| 节奏 | 快（短句密集） / 慢（铺陈细节） / 打断（插叙、自我纠正） |
| 情绪基调 | 吐槽 / 冷静复盘 / 兴奋安利 / 后悔劝退 |

**硬性要求**：每篇至少 **2 处**个人主观判断或真实经历细节（虚构但合理），例如「我个人特别讨厌这种设计」「如果让我重来，我会直接放弃这个库」。

## 四、结构自由化

- **开头**（随机选）：直接扔核心代码 / 抛问题 / 表态度 / 引对话。**禁止**以「随着……生态的快速发展」等空泛背景开头。
- **正文**：能自然叙述就**不用 bullet points**；仅真正的步骤列表才用编号。
- **结尾**：开放性问题 / 干脆判断 / 对未来版本的期待。**绝对禁止**「综上所述 / 总而言之 / 本文介绍了」+ 带编号总结。

## 五、结构模式（与上一篇不同）

| 模式 | 骨架 | 适配文章类型 |
|---|---|---|
| **模式 A · 叙事流** | 问题 → 尝试 → 解决 → 反思 | 踩坑复盘型、日记/流水账式 |
| **模式 B · 观点先导** | 观点/代码 → 分段论证 → 例外 → 一句收尾 | 反常识结论型、方案弃坑/对比型、冷门技巧型 |

> 生成前 MUST 读取 `index.json` 最近一条记录，本次选用**不同的**「结构模式 / 视角 / 人称 / 节奏 / 植入角度」组合。

## 六、质量门禁自查清单（生成后逐项，命中即重写）

- [ ] 开头用「随着……的发展 / 在当今……时代 / 近年来」
- [ ] 结尾「综上所述 / 总而言之 / 本文详细介绍了」
- [ ] 总结用数字列表（1.2.3.4.）
- [ ] 全文无个人主观判断/经历细节（要求 ≥2 处）
- [ ] 出现禁用词表中任意词
- [ ] 段落结构过于工整（每段首句都是概括句）
- [ ] 代码示例不可运行或未标语言
- [ ] 三版本摘要超字数
- [ ] 标签不符（要求 3–5 个且与内容紧密相关）
- [ ] 个人介绍泄露隐私（手机号 / 邮箱 / 微信号 / 住址）
- [ ] 许可证声明缺失
- [ ] 标题含禁用词
- [ ] `{{占位符}}` 原样残留
