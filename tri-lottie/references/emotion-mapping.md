# 情绪 → 运动映射

## 核心映射表

| 情绪 | 性格 | 路径 | 缓动 | 时长 |
|------|------|------|------|------|
| 喜悦/愉悦 Joy | 弹跳、弧线、过冲 | 曲线向上 | ease-out-back | 200-400ms |
| 平静 Calm | 平滑流动 | 缓曲线 | sine ease-in-out | 500-1000ms |
| 紧迫 Urgency | 锐利快速直接 | 直线 | ease-out | 100-200ms |
| 悲伤/沉重 | 缓慢下沉 | 下垂曲线 | cubic ease-in-out | 600-1200ms |
| 惊讶 Impact | 突然扩张 | 径向向外 | ease-out-expo | 150-300ms |
| 优雅 Elegance | 缓慢克制 | 长平滑弧 | (0.4,0,0.2,1) | 400-700ms |
| 俏皮 Playful | 弹跳不规则 | 弧线/波浪 | ease-out-back | 200-350ms |
| 自信 Confidence | 直接果断 | 水平直线 | ease-out | 200-400ms |
| 好奇 Curiosity | 探索多变 | 混合/环形 | 多变 | 300-500ms |
| 温柔 Tenderness | 轻柔 | 极缓曲线 | soft ease-in-out | 600-1000ms |

信任 Trust 追加：平滑可预测、300-400ms、缓曲线。

## 路径语义学（Path as Language）

| 路径类型 | 语义 |
|---------|------|
| 折线/锐角 | 紧张、紧迫、机械 |
| 曲线/平滑 | 放松、友好、有机 |
| 螺旋 | 俏皮、奇幻 |
| 直线对角 | 动感、目的性 |
| 垂直向上 | 成长、达成 |
| 垂直向下 | 落定、重力 |
| 水平 | 旅程、进程 |
| 径向向外 | 爆发、释放 |
| 径向向内 | 聚焦、收敛 |

## 方向语义（属性层）

position：上=成长/提升；下=落定/完成；左=回退/离开；右=前进/到达；向心=聚焦；离心=分发。
scale：放大=重要/激活；缩小=降级/远离；脉冲=关注/心跳；呼吸=存在/等待。
opacity：淡入=到达/启用；淡出=离开/禁用；半透明=次要/禁用态。**重要状态变更禁纯 opacity**（CRITICAL 门）。
rotation：5-15°=微调；45-90°=变换；360°=完成/处理中；连续=进行中。

## 情绪强度分级

| 强度 | 特征 | 适用 |
|------|------|------|
| 低 | subtle 透明度、微位移 | 环境、日常 |
| 中 | 可见但不索取注意力 | 多数 UI 交互 |
| 高 | 索取注意力、大位移 | 错误、庆祝、引导 |

## 色彩心理学（动效搭配）

| 颜色 | 情绪 | 动效搭配 |
|------|------|---------|
| 蓝 | 信任、平静 | 平滑中等过渡 |
| 绿 | 成功、成长 | 向上、扩张、轻过冲 |
| 红 | 警示、紧迫 | 锐利快速、水平抖动 |
| 橙 | 活力、温暖 | 弹跳、对角路径 |
| 紫 | 高级、神秘 | 缓慢揭示、优雅缓动 |
| 黄 | 乐观、注意 | 快速脉冲 |
| 青 | 现代、清晰 | 干净利落切换 |

**色彩过渡规则**：Success 过渡到绿色（不要以绿开场）；Error 红色闪现后回落（不要持续红）；Warning 黄/琥珀脉冲；中性用 opacity 而非色变。
