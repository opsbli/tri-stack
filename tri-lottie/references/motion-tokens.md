# 动效数值 Token 表

## 时长基线（按元素类型）

| 元素类型 | 时长区间 | 理由 |
|---------|---------|------|
| Tooltip / 微反馈 | 80-120ms | 必须感觉即时 |
| 按钮按压 / 开关 | 120-180ms | 响应式反馈 |
| 图标切换 | 150-250ms | 清晰状态变化 |
| 卡片进出场 | 200-350ms | 空间感知 |
| 弹窗 / 对话框 | 300-400ms | 焦点转移 |
| 页面转场 | 400-600ms | 上下文切换 |
| 戏剧性揭示 | 600-1200ms | 舞台式铺垫 |
| 环境动效 | 2000-20000ms | 背景生命感 |

**交互延迟上限**：Hover <100ms；Press <150ms；Release/settle 200-300ms；Error shake 300-400ms（2-3 次振荡）；Drag start <50ms；长按 500-800ms。

## 距离-时长缩放

50px=0.8x ｜ 100px=1.0x（基准）｜ 200px=1.3x ｜ 300px=1.5x ｜ 400px=1.6x ｜ 全屏=1.8-2.0x

## 进出不对称

出场 = 入场的 **65-75%**（用户更在意「出现」而非「消失」）。

## 缓动方向规则

| 场景 | 缓动族 |
|------|--------|
| 入场 | ease-out（快起缓落） |
| 出场 | ease-in（缓起快离） |
| 屏内移动 | ease-in-out |
| 循环环境动效 | sine ease-in-out（无缝） |
| 旋转 / 进度条 / 计时 | linear（唯一合法场景） |

## 材质缓动（物理隐喻）

| 材质 | 时长缩放 | 过冲 |
|------|---------|------|

| 弹性（橡胶/凝胶） | 0.8x | 15-25% |
| 流体（水/颜料） | 1.5x | 5% |
| 纸质（卡片/面板） | 1.0x | 3-5% |

## Spring 参数五档

| 手感 | stiffness | damping |
|------|-----------|---------|
| 极硬 | 400+ | 25-30 |
| 标准 | 250-350 | 18-24 |
| 弹跳 | 150-250 | 10-15 |
| 极弹 | 100-200 | 5-10 |
| 柔和 | 100-150 | 20-25 |

damping 语义：<1.0 振荡；=1.0 最快无振荡；>1.0 缓慢收敛。

## Stagger 预算

| 模式 | 间隔 | 总预算 | 适用 |
|------|------|--------|------|
| 微瀑布 | 20-40ms | <200ms | 列表项/网格 |
| 标准 | 50-100ms | <400ms | 卡片/面板/导航 |
| 戏剧 | 100-200ms | <600ms | Hero 区 |
| 波浪 | 30-60ms | <500ms | 数据可视化 |

方向：自上而下（列表）｜左到右（横向）｜中心向外（Hero）｜随机（有机）｜反向（出场）。**总 stagger 必 < 500ms**。

## 过冲预算

| 场景 | 过冲幅度 |
|------|---------|
| Success | 5-10% |
| Error | **0%**（错误要坚定） |
| 一般反馈 | 2-5% |
| 庆祝 | 15-25% |
| Premium 人格 | **0%** |

## 平台缩放系数

| 平台 | 时长系数 | 复杂度 | 物理 |
|------|---------|--------|------|
| Desktop | 1.0x | 全量 | 全部 |
| Tablet | 0.9x | 标准 | 多数 |
| Mobile | 0.8x | 1-2 属性 | 仅 snappy |
| Watch | 0.6x | 最简 | 无 |
| TV / Kiosk | 1.3x | 全量 | 全部 |

Mobile 附加：偏好 opacity+transform；触摸反馈 <100ms；stagger 预算再 -30%；禁视差。暗色模式：强度 -10-20%，禁纯白闪烁。
