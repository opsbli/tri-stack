## 一、判定字段说明

| 字段 | 含义 | 判定标准 |
|---|---|---|
| **激活条件** | skill 是否被正确激活 | 收到 tri-intent 快照且 L2 ∈ {I01–I05} |
| **子意图路由** | 按 L2 选择对应作答策略 | I01 事实/I02 分层/I03 建议/I04 利弊/I05 推导，不可混用 |
| **自检声明** | 作答前一句话声明 | 含意图/已读快照/作答策略/任务要点数 4 要素 |
| **来源标注** | 事实性主张来源标注 | 句末或段末「来源：xxx」；无法核实标注「未核实」 |
| **覆盖完整性** | 任务要点全覆盖 | 逐项核对，信息不足显式标注 |

## 二、评分规则

- 每条用例核心断言全部命中记 **PASS**，任一不符记 **FAIL**
- 通过率 = PASS 数 / 总用例数
- **质量门槛**：元数据/输入契约/职责边界场景 ≥95%，执行契约/自检声明/交付产物场景 ≥90%，整体 ≥90% 视为达标

- **前置条件**：L2=I05，作答含推导/计算过程
- **测试步骤**：1. 检查推导过程；2. 校验步骤正确性与完整性
- **预期结果**：推理计算步骤正确无跳步，推导过程可复算
- **通过标准**：PASS——步骤正确且可复算；FAIL——跳步或错误

### TC-08-03：覆盖完整性——任务要点全覆盖
- **前置条件**：作答完成
- **测试步骤**：1. 提取任务要点清单；2. 逐项核对覆盖情况
- **预期结果**：任务要点全部条目有对应作答，信息不足条目显式标注
- **通过标准**：PASS——全覆盖（含信息不足标注）；FAIL——存在遗漏

### TC-08-04：格式合规性——符合 D4_输出期望 + D4_格式约束
- **前置条件**：快照含 D4_输出期望 与 D4_格式约束
- **测试步骤**：1. 提取 D4 约束；2. 校验作答篇幅与格式
- **预期结果**：作答篇幅/格式与快照约束一致（简答/长文/分步指引 + 表格/分点/字数限制）
- **通过标准**：PASS——格式与约束一致；FAIL——格式不符

### TC-08-05：子意图匹配——作答策略与 L2 子意图对应
- **前置条件**：L2 为 I01–I05 中某一子意图
- **测试步骤**：1. 提取 L2 子意图；2. 校验作答策略映射
- **预期结果**：作答策略与 L2 子意图对应（I01 给事实 / I02 分层 / I03 给建议 / I04 列利弊 / I05 展推导），策略与子意图映射一致
- **通过标准**：PASS——策略与子意图映射一致；FAIL——映射错误

### TC-08-06：来源诚实性——无法核实标注「未核实」
- **前置条件**：作答含无法核实的主张
- **测试步骤**：1. 检查无法核实主张；2. 校验标注
- **预期结果**：无法核实的主张显式标注「未核实」
- **通过标准**：PASS——标注「未核实」；FAIL——未标注

### TC-08-07：来源诚实性——无编造来源
- **前置条件**：作答含来源标注
- **测试步骤**：1. 检查所有来源标注；2. 校验是否编造来源
- **预期结果**：无编造来源，NEVER 编造来源
- **通过标准**：PASS——无编造来源；FAIL——存在编造来源
