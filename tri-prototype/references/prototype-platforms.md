# 支持的原型平台清单

> 本文件是 `tri-prototype` 原型解析的平台适配单一事实源。
> 新增平台时在此追加一行（URL 特征 / 解析策略 / 保真度），解析逻辑自动适用。

---

## 支持的平台

| 平台 | URL 特征 | 解析策略 | 保真度 | 说明 |
|---|---|---|---|---|
| **Axure**（公开 share） | `share.axure.com` / `*.axshare.com` | 抓取页面 HTML → 解析 DOM 结构（面板 / 按钮 / 输入框 / 交互事件） | **高**（≥80%） | 公开可访问时可直接解析；含密码的链接须用户提供密码 |
| **Axure**（本地导出 HTML） | 本地目录（含 `.html`） | 逐文件解析 DOM 结构 | **高**（≥80%） | 用户导出后提供本地路径 |
| **Figma**（公开 link） | `figma.com/file/` 或 `figma.com/design/` | 抓取页面元数据 → 解析画板结构（Frame / 组件 / 文本） | **中**（50–80%） | 无 Figma API 时依赖公开可访问的分享链接；交互标注需用户补充 |
| **摹客**（MockingBot） | `mockingbot.com` / `app.mockingbot.com` | 抓取分享页元数据 → 解析页面清单与标注 | **中**（50–80%） | 结构化程度有限，交互规则需用户补充 |
| **墨刀**（Modao） | `modao.cc` | 抓取分享页元数据 → 解析页面清单与标注 | **中**（50–80%） | 同摹客 |
| **蓝湖**（Lanhu） | `lanhuapp.com` | 抓取分享页元数据 → 解析设计稿标注 | **中**（50–80%） | 设计标注为主，交互规则需 PRD 补充 |
| **即时设计**（JsDesign） | `js.design` | 抓取分享页元数据 → 解析画板结构 | **中**（50–80%） | 同摹客 |
| **PRD 文档**（web / file） | 任意 URL 或本地路径（`.md` / `.docx` / `.pdf`） | 读取文档 → 提取业务规则与验收标准 | **取决于文档内容** | PRD 独立使用时保真度=低（无原型结构），但业务规则覆盖完整 |
| **未知平台** | 不匹配以上特征 | 请求用户提供截图 / 导出文件 / 口头描述 | **低**（<50%） | NEVER 编造页面结构 |

---

## 保真度分级

| 级别 | 条件 | 产出可信度 | 处置 |
|---|---|---|---|
| **高**（≥80%） | 本地文件 / Axure 公开链接 | 页面结构 + 交互标注完整 | 直接产出 `requirements.md` |
| **中**（50–80%） | 在线原型链接（公开可访问） | 页面清单可提取，交互规则需用户补充 | 产出 + 标注待补充项 |
| **低**（<50%） | 链接不可访问 / 仅 PRD / 仅口头描述 | 仅能从 PRD 提取 | 产出 + 显式告知信息不足，请求补充 |

---

## PRD 解析格式

| 格式 | 来源 | 解析策略 |
|---|---|---|
| Markdown（`.md`） | 本地文件 / web URL | 直接读取，按标题层级提取业务规则与验收标准 |
| Word（`.docx`） | 本地文件 | 读取文档 → 提取正文表格与段落 |
| PDF | 本地文件 | 读取文档 → 提取文本 |
| Web PRD（语雀 / Confluence / Notion 等） | URL | 抓取页面 → 提取正文 |

> PRD 与原型**冲突**时，**以 PRD 为准**（PRD 是业务规则的权威来源），并在 `requirements.md` 中标注冲突项。
