# ADR 模板

```markdown
# {NNNN}. {决策标题}

## 背景

{为什么要做这个决策？遇到了什么问题？}

## 决策

{决定了什么？用一句话概括。}

## 理由

{为什么选这个方案而不是别的？}

## 替代方案

| 方案 | 不选的原因 |
|---|---|
| {方案 A} | {原因} |
| {方案 B} | {原因} |

## 后果

### 正面
- {好处}

### 负面
- {代价 / 限制}
```

## 命名规则

```
docs/adr/{NNNN}-{kebab-case-title}.md
例：docs/adr/0001-postgres-for-write-model.md
```

## 规则

1. ADR **不可变**：一旦写入 NEVER 修改正文。决策变更 → 新增一条新 ADR。
2. 新 ADR 的「背景」段 MUST 引用被取代的旧 ADR 编号。
3. 编号递增，NEVER 重用。
