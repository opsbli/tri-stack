# Changelog

本项目所有值得记录的变更均记录于此文件。

格式遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.0.0/)，

## [1.1.1] - 2026-09-18

### 新增

- **职责边界补「不触发场景（Not-Trigger）」**（对齐全家族 skill 写作规范）：明确本 skill 不接手从零创作原文撰写（tri-article / tri-content）、事实真伪核查（tri-true）、翻译转换本身（tri-content / tri-translate）与意图识别（tri-intent），强化「横向改写、不认领 L2」边界。

## [1.1.0] - 2026-09-18

### 新增

- **核心规则速查 5 条（粗筛层）**：删填充 / 破公式 / 变节奏 / 信读者 / 删金句，置于 35 模式表之前做「先粗后细」分层；明确粗筛不替代精判、与契约冲突时契约优先
- **人味注入（加法层）**：启用判据表（有样本按样本 / 个人写作启用 / 参考技术法律文本不注入）+ 注入 6 法 + 无灵魂迹象 6 条 + 中文 Before-After 示例；内置刹车条款（只注入观点与感受，NEVER 注入事实）
- **三问六检**：原双问自检升级为三问（AI 腔 / 事实增删 / 人味是否补足）+ 交付前六项清单（句长 / 结尾 / 破折号 / 解释隐喻 / 连接词 / 三段列举）
- **质量自评（非门禁）**：直接性 / 节奏 / 信任度 / 真实性 / 精炼度 5 维 ×10 = 50，仅粘贴模式输出，明确不覆盖事实保真与误报检查
- **完整中文端到端示例**：Before → After → 逐条更改说明 → 事实核对（零增删）
- **中英文双触发词**：`references/ai-patterns.md` 35 种模式各补「中文触发词」行；N17 标题大写、N19 弯引号补「中文适配（不适用）」注记与中文替代信号

### 修复

- **破折号判定与处置分层（原规则自相矛盾）**：判定层——单个破折号 NEVER 视为 AI 腔证据；处置层——终稿 MUST 不含 —、–、中文全角破折号 ——，两者互不覆盖；处置例外收敛为三条（写作样本使用 / 第二手文本内部 / 代码块与元数据内部）；同步 SKILL.md 契约第 5 条、误报检查、references N14 与 TC-10/TC-11
- **术语统一**：「上游依赖检测三态」→「四态」（A 快照 / A0 待识别 / B 引导安装 / C 降级），同步 description、README、tests A2 与 TC-02
- **第五类类目更名**：「填充与对冲（N23–N35）」→「填充、对冲与结构套路（N23–N35）」，类目名与内含模式语义对齐
- **归类统一**：「2022-11-30 前的编辑」统一归入「保留的人类细节」（原在 SKILL 中误列误报检查，与 references 不一致）
- **契约第 3 条补注入裁决**：明确「可添加观点或反应」的适用边界——有样本按样本，无样本时个人写作启用、参考/技术/法律文本不注入
- **README 目录结构**：移除已删除的 `references/version-check-spec.md`（1.0.1 已归档，真源在 `tri-forge`），补录 SKILL.md 与 references 的新增章节
- **版本联动**：README 徽章 1.0.0 → 1.1.0，与 SKILL.md / CHANGELOG / _meta.json / tests 五处一致
- **去标识化**：移除 README「可回溯到 humanizer 原文示例」与 references「编号沿用 humanizer 原始编号」等上游溯源表述，改为中性索引描述
- **`scripts/check_update.py` 注释**：真源引用改指 `tri-forge/references/version-check-spec.md`，消除对包内已移除文件的指向
