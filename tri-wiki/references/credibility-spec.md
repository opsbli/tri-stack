# 内容可信度评分与转载独立性规范（tri-wiki 治理层 · 唯一真源）

> grep 模式：`可信度|credibility|分量|权重|地板|重归一|转载|dup_group|独立`
> 可执行实现：`scripts/credibility_score.py`。本文件是规范唯一真源，脚本是算法唯一实现；两者冲突时以脚本实测为准并回写本文件。

---

## 1. 为什么需要可信度评分

v1 的质量报告只测**结构**（覆盖率 / 组织完整度 / 断链率），不测**内容**。结果是：一篇 3000 字的原始 PDF 全文和一篇 200 字的转载摘要，在质量报告里完全等价。

可信度评分把「这篇值不值得信」变成持久、可比、可排序的数值，供三处消费：
1. 质量报告的复核项按分数倒序排列（先看最可疑的）；
2. `--ranked` 式检索排序（若下游 RAG 接入）；
3. 生命周期推进的输入（低分笔记不晋升 evergreen）。

**诚实边界**：评分是**启发式合成**，不是事实判定。它回答「这篇的元证据强不强」，NEVER 回答「这篇说得对不对」。

## 2. 五分量与权重

| 分量 | 权重 | 计算口径 | 缺失时 |
|---|:--:|---|---|
| `provenance` 来源可追溯 | 0.30 | 有 `source`(0.5) + 有 `source_format`(0.25) + 有 `converter`/`split_from`(0.25) | 置 None，重归一 |
| `integrity` 元数据完整 | 0.20 | frontmatter 五个必填字段的命中率 | 置 None，重归一 |
| `substance` 正文信息量 | 0.20 | 0.7×长度分（log 曲线，4000 字满分）+ 0.3×结构分（≥5 个标题满分） | 导航页置 None；近空则触地板 |
| `linkage` 链接连通 | 0.15 | 反向链接数 / 全库最大反向链接数 | 无链接时置 None |
| `freshness` 时效 | 0.15 | 0.5^(天数 / 540)，即约 18 个月半衰 | 无日期置 None |

**权重常量**位于 `scripts/credibility_score.py:WEIGHTS`，改权重只改该字典，NEVER 改流程。

### 2.1 缺失分量重归一化（关键设计）

某分量无法计算时（例如没有日期），**不是按 0 计入**，而是把它的权重从分母里剔除：

```
score = Σ(w_i × v_i) / Σ(w_i)   —— 仅对存在的分量求和
```

理由：缺日期不该让一篇好笔记被判死；这与「不可计算指标显式标注不适用」的诚实原则一致。报告中同时输出 `missing_components` 与 `basis`（`full` / `renormalized` / `floor`），让分数可解释。

### 2.2 硬地板

| 触发 | 分数 | 语义 |
|---|---|---|
| `status ∈ {deprecated, archive}` | 0.05 | 已废弃，不参与排序竞争 |
| 正文有效字符 < 10 | 0.05 | 近乎空壳 |

**NEVER 触地板的情形**：`type ∈ {index, moc, tags}` 的导航页天然短小，其 `substance` 分量置 None 走重归一化，绝不能因为短而被压地板。

## 3. 转载独立性聚类

「五家媒体转载同一篇通稿」在知识库里表现为五个近乎相同的内容，若各计一票会虚增覆盖度。聚类把衍生副本折权：

- **算法**：3-shingle 集合的 Jaccard 相似度 ≥ 0.70 视为同一簇（阈值 `--threshold` 可调）；
- **折权**：簇内每篇的最终分除以簇大小（`1/size`），最早入库者保留相对优势；
- **输出**：`credibility.json` 的 `derivative_cluster` 字段 + `clusters` 列表；`dedup-report.json` 给出 `suggested_keep` / `suggested_flag`。

**聚类只标记、不删除**。哪一份保留、哪一份合并，永远由用户仲裁——本 skill 只把「这几篇可能是同一份」摆到台面上。

## 4. 与质量报告的接口

`quality_check.py` 读取 `.wiki-meta/credibility.json`，把三项并入质量报告：

| 报告字段 | 来源 |
|---|---|
| 可信度均值 / 中位 | `summary.mean` / `summary.median` |
| 触地板篇数 | `summary.floor_hits` |
| 转载簇数 / 涉及篇数 | `summary.derivative_clusters` / `derivative_notes` |

可信度**不参与 A/B/C 置信度分级**（分级仍由结构指标决定），只作为复核项排序依据——结构合格而内容可疑，仍然给出 B 级并标注重核项。

---

## 5. 校准纪律（诚实约束）

权重与阈值来自「参考项目启发 + 中文语料校准」，**不是经过验证的通用标尺**：

- 首次在真实知识库上运行时，MUST 先看 `summary` 的分布再决定是否调参；
- 调参只改 `scripts/credibility_score.py` 顶部常量，并同步回写本文件 §2 表格；
- 报告中 MUST 标注「可信度为启发式评分，非事实判定」。
