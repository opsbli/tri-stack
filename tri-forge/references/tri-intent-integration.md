# 门③ 子路由回填规则（tri-intent 集成）

> **本文件是「生成物若具备 tri-intent 下游身份，须回填哪些真源」的单一事实源。**
> 门③ 强制：**NEVER 只生成 skill 而不接通路由**——未回填的 skill 在家族里是「孤儿」，
> 用户命中该路由时会落到兜底或报错。

---

## 一、触发条件

门③ 仅在生成物**具备 tri-intent 下游身份**时执行。判据是「是否认领 L2/L3 意图编码」：

| 角色 | 是否认领 L2/L3 | 门③ |
|---|---|---|
| 路由型下游 | ✅ | **必须执行**（含 L3 子类） |
| 横向型 | ❌ | 跳过（但若被 hook/委派激活，须在 `family-spec.md` §五 登记激活方式） |
| 内部工具型 | ❌ | 跳过（不注册下游；若可被委派，登记委派方） |
| children 子 skill | ❌ | 跳过（随父包分发，不参与路由表） |

---

## 二、回填清单（路由型下游 MUST 逐项完成）

| # | 回填对象 | 位置 | 动作 |
|---|---|---|---|
| 1 | **路由映射表** | `tri-intent/SKILL.md` §一 路由映射表 | 追加/更新该 L2 对应行，指向新 slug |
| 2 | **L3 子类说明** | 同上，L3 子类路由说明段 | 若为子类一跳路由，追加该子类的说明段（判定语义 + 与相邻子类的消歧 + 优先级） |
| 3 | **下游依赖检测** | `tri-intent/scripts/check_downstream.py` 的检测位置清单 | 确认检测路径已覆盖新 slug 的落盘位（家族源码树 / `.tribro/skills/` / 平台用户级 / 平台项目级）；**所需仅检测目录存在性，脚本通常无需改动** |
| 4 | **计数表述** | `tri-intent/SKILL.md` 及 README 中涉家族的表述 | **不得写硬编码计数**（硬约束第 17 条）；若原文有计数，改为描述性表述 |
| 5 | **README 表** | 仓库根 `README.md` 的技能目录/分类表 | 追加新 skill 行，归入正确的角色分类 |
| 6 | **落盘约定** | `tri-intent/SKILL.md` §输入契约 或快照模板 | 若新 skill 产出链路文档，确认 `.tribro/<域>/` 命名约定一致 |

---

## 三、回填顺序（不可颠倒）

```
1. 生成 skill 包（门② 产物）
      │
2. 回填 tri-intent 路由真源（本节 §二 第 1–2 项）
      │
3. 校验 MECE：交叉比对 tri-intent/SKILL.md §路由映射表
      │  └─ 若目标 L2 已被其他 skill 认领 → 停止，改为申请 L3 子类，或回炉门② 改设计
      │
4. 回填其余项（§二 第 3–6 项）
      │
5. 进入门④ 合规自检
```

**为什么 2 在 3 之前**：门④ 第 8 条「MECE 不重叠」需要比对**已回填后**的路由表。
若先自检后回填，比对的是旧表，**漏检路由冲突**。

---

## 四、优先级仲裁（多个子类同时命中时）

家族既有的子类优先级（生成新子类时 MUST 遵守并保持传递性）：

```
真实项目交付（sdlc）  >  流程定义产物（workflow）  >  长期循环体（loop）
```

判定口径是**交付对象是什么**，而非表层动词。生成新 L3 子类时 MUST：
1. 明确它的判定语义（触发词 + 消歧要点）
2. 声明它与既有子类的**优先级关系**（若可能同时命中）
3. 在 §二 第 2 项的子类说明段中写清消歧

---

## 五、二跳路由例外

若新 skill 采用「中介路由 + 具体执行」二跳形态（由中介 skill 委派具体执行 skill）：

- 门③ 只需回填**中介 skill** 为下游
- 被执行方**不注册为下游**，但 MUST 在中介 skill 内显式声明委派关系
- 下游依赖检测在二跳场景需**同时检测中介与被执行方**，任一缺失即提示安装
- 该二跳形态 MUST 在 `family-spec.md` §五 登记

---

## 六、回填后的自查（门③ 完成判据）

```
□ 路由映射表中该 L2 指向新 slug，且无第二行指向同类意图
□ 子类说明段含「判定语义 + 消歧要点 + 优先级」
□ 全文无硬编码家族计数
□ check_downstream.py 能检出新 slug 的落盘位
□ README 表已追加且分类正确
□ 交叉比对 tri-intent §路由映射表，该 L2/L3 未被其他 skill 认领
```

任一项不满足 → 门③ 未完成，**NEVER 进入门④**。
