# SWOT 分析（SWOT Analysis）

> 蒸馏自 `swot-analysis`｜域：战略｜源词数：约 520

## 必含章节清单（MUST-SECTIONS）

- [ ] 1. Strengths (Internal, Positive) — 优势（内部·正面）
- [ ] 2. Weaknesses (Internal, Negative) — 劣势（内部·负面）
- [ ] 3. Opportunities (External, Positive) — 机会（外部·正面）
- [ ] 4. Threats (External, Negative) — 威胁（外部·负面）

### 可选补充段（OPTIONAL）

- [ ] Output Process — 8 步流程
- [ ] Strategic Applications — 战略应用
- [ ] Notes

## 逐段引导问题

- **1. Strengths**：独特能力/专长？品牌认知/声誉？客户关系与忠诚？技术或 IP 优势？成本优势/运营效率？团队人才与经验？现有客户群/渠道？
- **2. Weaknesses**：资源约束（预算/团队/技能）？技术/基建限制？品牌认知弱？客户关系弱/高流失？相对竞品高成本？过时流程/遗留系统？依赖关键人或伙伴？
- **3. Opportunities**：增长中的细分/需求？技术革新带来新方案？有利的监管变化？竞品弱点/市场空白？合作或并购机会？进入相邻市场？客户偏好/行为转变？
- **4. Threats**：新兴/更强竞品？客户偏好变化？技术颠覆/过时？监管/合规风险？经济下行/市场收缩？供应链中断？供应商/伙伴整合？

## 输出模板

```markdown
# SWOT: [产品]

| Strengths | Weaknesses |
|-----------|-----------|
| [内部正面] | [内部负面] |

| Opportunities | Threats |
|--------------|---------|
| [外部正面] | [外部负面] |

### 交叉洞察
- 用优势抓机会 / 补劣势御威胁 / 机会克服劣势 / 威胁利用劣势

### 战略建议（3-5）
[行动 + 负责人 + 指标]
```

## 关键规则

- Output Process（8 步）：列 5-7 优势→5-7 劣势→5-7 机会→5-7 威胁→交叉洞察→3-5 战略建议→排优先级与负责人→设跟踪指标。
- Strategic Applications：Build（强化优势+机会）/ Defend（补劣势+御威胁）/ Pivot（改变竞争态势的机会）/ Exit（威胁过多且竞争位弱）。
- SWOT 是内部到外部的评估，需对比竞品与行业；随市场变化每季度更新；用于指导路线图、合作、资源配置。
