# 初创画布（Startup Canvas）

> 蒸馏自 `startup-canvas`｜域：战略｜源词数：约 700

## 必含章节清单（MUST-SECTIONS）

### Part 1: Product Strategy（9 段）

- [ ] 1. Vision — 愿景
- [ ] 2. Market Segments — 市场细分
- [ ] 3. Relative Costs — 相对成本
- [ ] 4. Value Proposition — 价值主张
- [ ] 5. Trade-offs — 战略取舍
- [ ] 6. Key Metrics — 关键指标
- [ ] 7. Growth — 增长
- [ ] 8. Capabilities — 能力
- [ ] 9. Can't/Won't — 防御性

### Part 2: Business Model（2 段）

- [ ] 10. Cost Structure — 成本结构
- [ ] 11. Revenue Streams — 收入流

### 可选补充段（OPTIONAL）

- [ ] Domain Context — 与 BMC/Lean Canvas 的区别
- [ ] Notes

## 逐段引导问题

- **1. Vision**：如何激励人？渴望达成什么？坚守什么价值？从简起步，愿景随战略演化。
- **2. Market Segments**：市场由人的问题定义（非人口统计）；JTBD、期望结果、约束；第一个客户细分是谁？为何先做它？
- **3. Relative Costs**：优化低成本（Southwest）还是独特价值（Starbucks）？低成本不必然等于低价格。
- **4. Value Proposition**（每细分）：What before（现有问题状态）；How（改变现状的功能）；What after（收益与结果）；Alternatives（你相对竞品/替代品的独特价值，可用 Value Curve）。
- **5. Trade-offs**：不做什么？取舍创造专注、放大价值。对初创尤重要。
- **6. Key Metrics**：衡量产品与战略是否奏效的几个指标；North Star 与本季度 OMTM。
- **7. Growth**：PLG 还是 Sales-Led？偏好渠道：社媒、SEO、KOL、分销商？
- **8. Capabilities**：需获取哪些能力/资源？自建还是合作？
- **9. Can't/Won't**：为何对手不能或不愿复制？整套战略都应难复制，而非单点；各元素是否契合且互相强化？
- **10. Cost Structure**：租金、硬件、许可、技术、营销、订阅、薪资；哪些是可重复的？如何随规模扩张？
- **11. Revenue Streams**：每渠道多少钱？定价取向：渗透/价值/竞争/用量/SaaS？收入模型可规模化吗？最大不确定性？

## 关键规则

- 将战略与商业模式分离，但保持连接。
- 战略须通过 Can't/Won't 测试：对手不能/不愿复制这套整合选择。
- 起草首版后识别并启动假设测试。
- 可混合调整各画布以适应需求，不必死守。
- Output Process（13 步）：愿景→2-3 细分含 JTBD→成本定位→各细分价值主张→显性取舍→North Star+OMTM→增长策略→能力→防御性→估算成本结构与收入流→校验一致性→暴露假设→建议低成本实验。
