# 商业模式画布（Business Model Canvas）

> 蒸馏自 `business-model`｜域：战略｜源词数：约 650

## 必含章节清单（MUST-SECTIONS）

### Left Side: Creating Value（创造价值）

- [ ] 1. Key Partners — 关键合作伙伴
- [ ] 2. Key Activities — 关键业务
- [ ] 3. Key Resources — 关键资源

### Center: The Value Proposition（价值主张）

- [ ] 4. Value Propositions — 价值主张

### Right Side: Delivering Value（交付价值）

- [ ] 5. Customer Relationships — 客户关系
- [ ] 6. Channels — 渠道
- [ ] 7. Customer Segments — 客户细分

### Bottom: Financial Viability（财务可行性）

- [ ] 8. Cost Structure — 成本结构
- [ ] 9. Revenue Streams — 收入流

### 可选补充段（OPTIONAL）

- [ ] Domain Context — 与 Lean/Startup Canvas 对比
- [ ] Notes

## 逐段引导问题

- **1. Key Partners**：关键战略伙伴与供应商？哪些合作支撑模式？伙伴承担哪些活动？有无合资/共创？
- **2. Key Activities**：业务执行哪些关键活动？哪些流程对交付价值关键？自建还是外包？生产/解决问题/平台网络活动？
- **3. Key Resources**：创造价值必需的资源？实物/IP/人力/财务？支撑活动与伙伴的资源？最小可行资源集？
- **4. Value Propositions**：交付什么价值？解决哪些客户问题？满足哪些需求？每个细分对应什么产品/服务？定量（价格/速度/质量）vs 定性（设计/地位）？
- **5. Customer Relationships**：如何建立维护关系？人工协助/自助/自动/社区/共创？获客与留存成本？如何保持参与？
- **6. Channels**：客户如何发现并获取价值？认知/购买/交付/售后各阶段？直销 vs 间接、自有 vs 伙伴？
- **7. Customer Segments**：关键客户细分？大众/利基/细分/多边平台？定义特征？不同需求/渠道/关系/盈利？
- **8. Cost Structure**：最重要的成本？固定 vs 可变？成本驱动（规模/自动化/人力/基建）？成本驱动型还是价值驱动型？
- **9. Revenue Streams**：如何赚钱？单客/单笔/订阅/许可/租金？定价机制（固定/动态/价值）？LTV 与单位经济？

## 关键规则

- BMC 提供价值如何在组织内流动的全局视图。
- 每块应互相强化支撑。
- 强商业模式有清晰、可防御的价值主张。
- 财务可持续要求规模下收入 > 成本。
- 输出流程含经济可行性测试：**LTV > 3x CAC**（生命周期价值大于 3 倍获客成本）。
- Domain Context：BMC 缺愿景、缺 Can't/Won't 防御测试、缺取舍、缺关键指标、Key Partnerships/Resources 对早期产品价值低。新产品的推荐替代是 Startup Canvas。
