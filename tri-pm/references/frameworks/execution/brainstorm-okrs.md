# 团队 OKR 构思（brainstorm-okrs）

> 蒸馏自 `brainstorm-okrs`｜域：执行｜源词数：≈580

## 必含章节清单（MUST-SECTIONS）

- [ ] Set 1 — Objective + 3 Key Results + Rationale
- [ ] Set 2 — Objective + 3 Key Results + Rationale
- [ ] Set 3 — Objective + 3 Key Results + Rationale

（3 套方案等权重；每套含：定性激励型 Objective、恰好 3 个可量化 KR、简要理由）

### 可选补充段（OPTIONAL，不参与 BLOCK 判定）

- [ ] 公司战略对齐说明（每套如何 ladder up 到公司目标）

## 逐段引导问题

- **Objective**：团队可为之振奋的定性、有时间限的目标？应 SMART。
- **Key Results**：3 个可量化指标（通常），预期值？置信 60-70%（有雄心但可达）。
- **Rationale**：为何对公司与团队重要？
- **Alignment**：团队努力如何 ladder up 到公司目标？

## 输出模板

```markdown
Objective: [定性、激励型陈述]
Key Results:
- [Metric] >= [target]
- [Metric] >= [target]
- [Metric] <= [target]
（每套附 1-2 句 rationale）
```

## 输出命名规则

`OKRs-[team-name]-[quarter].md`（内容充实时保存）

## 关键规则

- OKR（Christina Wodtke《Radical Focus》）：Objective=定性/激励/时间限；KR=定量（通常 3 个）。
- OKRs / KPIs / North Star Metric 相互关联非替代：KR 可含 KPI；NSM=单一客户中心 KPI（业务成功先行指标）。
- 每个 KR 须独立可测；避免输出导向指标（如「上线 5 个功能」），聚焦结果。
- 3 套方案皆可信，不刻意让某一套明显更优。
- 标注数据可得性假设。
