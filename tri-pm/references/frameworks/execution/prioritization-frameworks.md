# 优先级框架参考（prioritization-frameworks）

> 蒸馏自 `prioritization-frameworks`｜域：执行｜源词数：≈600

## 核心原则

NEVER 让客户设计解决方案。优先**问题（机会）**，而非功能。

## 必含章节清单（MUST-SECTIONS）— 9 种框架全列

- [ ] Opportunity Score（Dan Olsen《The Lean Product Playbook》）— 推荐用于客户问题
- [ ] ICE — 想法/举措快速优先级
- [ ] RICE — 规模化想法
- [ ] Eisenhower Matrix — 个人任务
- [ ] Impact vs Effort — 任务/举措 2×2
- [ ] Risk vs Reward — 举措（含不确定性）
- [ ] Kano Model — 理解期望（非排序用）
- [ ] Weighted Decision Matrix — 多因子决策
- [ ] MoSCoW — 需求（Must/Should/Could/Won't）

## 逐段引导问题 / 公式（逐条照抄）

- **Opportunity Score**：Importance×Satisfaction 归一 0–1。
  - Current value = Importance × Satisfaction
  - Opportunity Score = Importance × (1 − Satisfaction)
  - Customer value created = Importance × (S2 − S1)（S1 前满意度，S2 后）
  - 高 Importance + 低 Satisfaction = 最高机会分；画 Importance vs Satisfaction 图，左上象限为甜区。
- **ICE**：I=Opportunity Score×受影响客户数；C=Confidence(1-10)；E=Ease(1-10)。Score = I×C×E。
- **RICE**：R=Reach（客户数）；I=Impact（机会分/客户）；C=Confidence(0-100%)；E=Effort（人月）。Score = (R×I×C)/E。
- **Eisenhower**：紧急 vs 重要——个人 PM 任务管理。
- **Impact vs Effort**：简单 2×2 快速分诊，战略不严谨。
- **Risk vs Reward**：同 Impact vs Effort 但纳入不确定性。
- **Kano**：Must-be/Performance/Attractive/Indifferent/Reverse——理解期望。
- **Weighted Decision Matrix**：给准则赋权，给选项打分——利干系人认同。
- **MoSCoW**：Must/Should/Could/Won't——注意项目管理起源。

## 输出模板（9 框架速查表）

| Framework | Best For | Key Insight |
|-----------|----------|-------------|
| Eisenhower Matrix | Personal tasks | Urgent vs Important |
| Impact vs Effort | Tasks/initiatives | Simple 2×2 quick triage |
| Risk vs Reward | Initiatives | Accounts for uncertainty |
| **Opportunity Score** | Customer problems | **Recommended.** Importance×(1−Satisfaction) |
| Kano Model | Understanding expectations | Must-be/Performance/Attractive |
| Weighted Decision Matrix | Multi-factor | Assign weights, score options |
| **ICE** | Ideas/initiatives | Impact×Confidence×Ease |
| **RICE** | Ideas at scale | (Reach×Impact×Confidence)/Effort |
| MoSCoW | Requirements | Must/Should/Could/Won't |
