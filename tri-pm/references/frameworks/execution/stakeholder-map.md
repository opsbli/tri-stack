# 干系人地图与沟通计划（stakeholder-map）

> 蒸馏自 `stakeholder-map`｜域：执行｜源词数：≈430

## 必含章节清单（MUST-SECTIONS）

- [ ] Stakeholder List — 列出所有相关个人/群体
- [ ] Power × Interest Classification — 每个干系人的权力/利益分级
- [ ] Grid Placement — 落入 4 象限
- [ ] Communication Plan — 每象限沟通频率/格式/关键信息
- [ ] Potential Conflicts — 利益冲撞与对齐策略

### 可选补充段（OPTIONAL，不参与 BLOCK 判定）

- [ ] （无）

## 逐段引导问题

- **Identify**：高管、工程负责人、设计、市场、销售、支持、法务、财务、外部伙伴、终端用户。
- **Classify**：Power（高/低，影响决策/资源能力）；Interest（高/低，受影响/参与度）。
- **Grid**：
  - 高权力×高利益 = Manage Closely（定期 1:1、早纳入决策）
  - 高权力×低利益 = Keep Satisfied（周期更新、仅升级关键问题）
  - 低权力×高利益 = Keep Informed（定期状态、邀演示、收反馈）
  - 低权力×低利益 = Monitor（轻触更新）
- **Per quadrant**：频率、格式、关键信息与框架、被忽视的风险。

## 输出模板

```markdown
| Stakeholder | Role | Power | Interest | Strategy | Frequency | Channel | Key Message |
|-------------|------|-------|----------|----------|-----------|---------|-------------|
（附 4 象限沟通建议 + 冲突标记）
```

## 关键规则

- 4 象限对应不同沟通频率/格式/关键信息
