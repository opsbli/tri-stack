## 逐段引导问题

- **Format A Start/Stop/Continue**：开始做什么 / 停止做什么 / 继续做什么。
- **Format B 4Ls**：Liked / Learned / Lacked / Longed For。
- **Format C Sailboat**：Wind（推动）/ Anchor（拖慢）/ Rocks（风险）/ Island（目标）。
- **Action Items**：限 2-3 项（多了做不完）；每项具体、可指派、可测；参考上轮是否完成。

## 输出模板

```markdown
## Sprint [X] Retrospective — [Date]
### Sprint Performance
- Goal: [Achieved/Partial/Missed] | Committed: [X] | Completed: [Y]
### Key Themes
1. [Theme] — [summary]
### Action Items
1. [Action] — [Owner] — [By date]
### Carry-over from Last Retro
- [Previous action] — [Done/In Progress/Not Started]
```
