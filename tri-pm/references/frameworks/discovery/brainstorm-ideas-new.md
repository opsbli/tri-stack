# 新产品构思（brainstorm-ideas-new）

> 蒸馏自 `brainstorm-ideas-new`｜域：探索｜源词数：323

面向新产品**初始探索（initial discovery）**的多视角构思。从 PM、Designer、Engineer 三视角生成**具体的功能想法（specific feature ideas）**。

**与同族三个技能的差异**：本技能 = 新产品 × 构思想法。与 `brainstorm-ideas-existing`（既有产品×构思）的关键分野在源文件的 Domain Context 里写明：Initial Discovery 关注 vision、business model、market validation，测的是**产品是否应该存在**；Continuous Discovery 与交付并行，是在活产品上不断学习迭代。本技能属**初始探索**。

## 必含章节清单（MUST-SECTIONS）

- [ ] Understand the opportunity — 理解机会：确认产品概念、目标市场细分、用户想达成什么
- [ ] Ideate from three perspectives — 三视角构思：每视角各产 **5 个具体功能想法**
- [ ] Prioritize the top 5 ideas — 跨视角优选前 **5 个**（新产品需特定权重）
- [ ] For each prioritized idea — 为每个入选想法给出推理与待测关键假设

### 可选补充段（OPTIONAL，不参与 BLOCK 判定）

- [ ] Domain Context — 领域背景：Initial Discovery vs Continuous Discovery 的区分
- [ ] 前置读取：用户若提供文件（market research、competitive analysis）先读；必要时用网络检索理解市场

## 逐段引导问题

- **Understand the opportunity**：确认 product concept、target market segment，以及 what the users want to achieve（用户想达成什么）。
- **Ideate from three perspectives**（各 5 个具体功能想法）：
  - **Product Manager**：聚焦 market fit、value creation、competitive advantage（市场契合、价值创造、竞争优势）
  - **Product Designer**：聚焦 user experience、onboarding、engagement（用户体验、上手引导、参与度）
  - **Software Engineer**：聚焦 technical innovation、API integrations、platform capabilities（技术创新、API 集成、平台能力）
- **Prioritize the top 5 ideas**——新产品要**重度倾斜**（weight heavily toward）以下三项（照抄）：
  - Core value delivery (does it solve the primary problem?)（核心价值交付：它解决了首要问题吗？）
  - Speed to validate (can we test this quickly?)（验证速度：能否快速测试？）
  - Differentiation potential（差异化潜力）
- **For each prioritized idea**：给出 reasoning（推理）与 key assumptions to test（待测关键假设）。

## 关键规则

- 三视角各产 **5 个**，且必须是 **specific feature ideas**（具体功能想法），不是宽泛方向。
- 新产品的优选权重与既有产品不同：不看「相对现有方案的差异化 + 战略对齐」，而看**核心价值交付、验证速度、差异化潜力**三项。
- 先读市场研究 / 竞品分析等既有材料，必要时检索市场信息，再构思。
- 领域纪律（源文件 Domain Context 原意）：本技能只服务 initial discovery；若产品已上线有真实用户，应改用 `brainstorm-ideas-existing`。
