## 逐段引导问题

**The 5 Growth Loop Types（类型划分与每类结构要素——逐类照抄）**

1. **Viral Loop（病毒闭环）**：用户创造的产品内容被分享到外部平台，把新用户带回产品。
   - Mechanism：用户产品内创建内容 → 分享到社媒/外部平台 → 新用户发现并注册
   - Example：Figma 设计以链接分享、Loom 视频在邮件中分享
   - Strength：若内容天然可分享则用户指数级增长
   - Challenge：需要高度可分享产出与强分享激励
2. **Usage Loop（使用闭环）**：用户在产品内创造内容或价值，再分享，从而邀请新用户或驱动再互动。
   - Mechanism：用户创建 → 分享创作 → 他人消费 → 成为活跃用户
   - Example：Twitter 推文、Medium 文章、Notion 模板公开分享
   - Strength：增长直接绑定产品使用与网络效应
   - Challenge：要求内容创作摩擦极低
3. **Collaboration Loop（协作闭环）**：用户邀请同事在产品内共创协作，在组织内扩张用户群。
   - Mechanism：用户创建 → 邀请同事协作 → 同事发现产品价值
   - Example：Google Docs 邀请、Figma 团队项目、Slack 频道
   - Strength：深度组织渗透与高留存
   - Challenge：最适合协作/团队型产品
4. **User-Generated Loop（用户生成闭环）**：用户通过他人创作发现新内容/功能，再创作并分享自己的内容。
   - Mechanism：用户发现内容 → 创作相似内容 → 分享创作 → 他人发现
   - Example：TikTok、Pinterest、YouTube 趋势驱动创作者参与
   - Strength：创造内容飞轮与网络效应
   - Challenge：需要足量优质内容维持
5. **Referral Loop（推荐闭环）**：用户为奖励/激励/社交认可邀请其他潜在用户。
   - Mechanism：用户推荐 → 被推荐者加入 → 推荐者获奖励 → 分享更多推荐
   - Example：Dropbox 推荐奖励、Uber 乘客推荐、PayPal 注册奖励
   - Strength：直接激励获客；ROI 易衡量
   - Challenge：需有价值的激励且不侵蚀单位经济

**How It Works（五步）**
- Step 1 Define Product Value：主动作、每动作创造价值、网络效应、体验摩擦点。
- Step 2 Evaluate Loop Fit：产品类型、目标行为与分享习惯、已有网络效应、现有用户与互动。
- Step 3 Design Loop Mechanics：触发分享/邀请的触发点、参与激励（内在/外在）、分享机制易用度、邀请到激活的转化率、每用户循环频率。
- Step 4 Calculate Loop Coefficient：每周期每用户邀请/分享数、邀请到新用户的转化率、每周期净新增、每周期迭代时间。
- Step 5 Build the Loop：从最高杠杆闭环先建、优化信息与摩擦、度量闭环指标、随时间复利。

## 关键规则

- 先精通一个闭环再加复杂度。
- 病毒闭环复利最快但需时间构建。
- 协作闭环创造最强留存与 LTV。
- 优化期每周度量闭环健康。
- 规模化后叠加闭环以获乘法效应。
