# 通用兜底蒸馏方法论（distill-general）

> 被 tri-god 在**无法**将对象归入 human/workflow/skill/thing 任一类时加载（兜底）。
> **核心信条**：任何可被蒸馏对象都有一个共性——其中藏着**可复用的模式/规则/框架**。本方法论的任务，就是把这些共性识别出来、原子化为一个可被 Agent 执行的 skill，而非泛泛描述对象。

## 引用合规（MUST）

- 引用他人素材单条 ≤150 字，MUST 保留出处；主体以「自述重写」承载知识。
- NEVER 整段照搬受版权保护内容；蒸馏产出须标注素材来源与署名，尊重许可证。
- 素材含敏感信息（商业机密/专有流程细节/个人隐私等）时，MUST 先与用户确认脱敏范围，蒸馏产物 NEVER 保留可识别的敏感细节。

## 优先归类原则（MUST）

进入本方法论前及过程中，MUST 持续判断对象是否其实更适合某个专门方法论：

| 若对象本质是… | MUST 建议切换到 |
|---------------|-----------------|
| 一个人的思维/表达 | distill-human |
| 一套可运转的流程 | distill-workflow |
| 一项专家技能/手艺 | distill-skill |
| 一段可通读的长内容 | distill-thing |

> 一旦识别出更贴切的专门归类，MUST 停下并建议切换，NEVER 用通用流程凑合处理本该专门蒸馏的对象。

## Phase 1 · 对象理解

MUST 先建立对象全貌，缺口不补齐 NEVER 进入拆解：

- **这是什么**：对象的本质、形态、所属范畴。
- **边界**：包含什么、不包含什么、与相邻对象的分界。
- **价值**：蒸馏它能给 Agent 带来什么可复用能力、解决什么问题。

## Phase 2 · 要素拆解

将对象拆到可分析的颗粒度：

| 拆解项 | 内容 |
|--------|------|
| 构成要素 | 对象由哪些组成部分/维度构成 |
| 关键规律 | 各要素间稳定的因果、关联、约束 |
| 可复用点 | 哪些要素/规律在对象之外仍成立、值得沉淀 |

## Phase 3 · 模式提炼

将可复用点抽象为可迁移的结构（核心产物）：

- 提炼出**可迁移的框架或规则**（模型/分类/原则/启发式，视对象而定）。
- MUST 每条模式可回溯到 Phase 2 的具体要素，NEVER 虚构对象不具备的规律。

## Phase 4 · 可执行化

将模式转成 Agent 可执行的形态：

- 转为 **1-2-3 步骤** 或 **决策清单**（含判断条件与去向）。
- MUST 可操作、不空泛，具体到「做什么、看什么」。

## Phase 5 · 验证与边界

MUST 对提炼结果过三重验证，未通过者剔除或修正，并标注边界：

| 验证 | 检验点 |
|------|--------|
| V1 · 可复现 | 换个情境按提炼的模式操作，能否复现结果 |
| V2 · 预测力 | 该模式能否预测新情境的走向 |
| V3 · 非常识 | 该模式是否非平庸、具独特价值 |

- **适用边界（MUST）**：模式在什么条件下成立、超出即失效。

## Phase 6 · 生成 skill + 压力测试

将上述封装为可独立调用的 skill：

- **SKILL.md**：定位（是什么/解决什么）+ 可迁移框架或规则 + 1-2-3 步骤/决策清单 + 适用边界，用 MUST/NEVER 约束行为；description MUST 明确 trigger。
- **压力测试（MUST）**：正例测试（应触发场景正确激活）+ 诱饵测试（看似相关实则不该触发的场景 NEVER 误触发）。
- **配套**：素材来源清单、署名、示例走查。

## 阶段化对接 tri-god 审批门

| tri-god 门 | 本方法论阶段 |
|---|---|
| 门① requirements.md | Phase 1 的对象本质、边界、价值、用途 |
| 门② design.md | 「加载 distill-general + 六阶段规划 + 归类复核结论」 |
| 门③ tasks.md | 拆解为要素拆解 → 模式提炼 → 可执行化 → 验证 → skill 构造 + 压力测试任务（含复选框） |
| 执行 → implements.md | Phase 2~6 执行记录 + 三重验证/压力测试结果 + 可追溯性核对 |

## 质量红线（全过方可交付）

- [ ] 提炼出可迁移的模式/规则/框架，且可回溯到真实要素。
- [ ] 全部模式通过三重验证（V1 可复现 / V2 预测力 / V3 非常识），并标注适用边界。
- [ ] 产出 skill 可独立调用、可执行不空泛，含诱饵压力测试且不误触发。
